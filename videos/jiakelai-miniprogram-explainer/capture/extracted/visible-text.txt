家客来（JoveKore）微信小程序产品说明

产品是什么
装修公司用家客来小程序，把获客、上门量房、AI 方案、客户交付收在同一条协作链上。不是互不相干的工具。客户、推荐人、家装设计顾问、家装现场顾问、企业负责人登录后进入各自工作台，数据和进度跟着身份走。一个账号可有多重身份，随时切换。

观众
内部讲解、渠道介绍、给装修公司老板看的产品说明。

不要讲
渠道地推、平台管理员单独成段。量房编辑器、AI 方案台不展开操作步骤。不读出客户手机号、精确地址、内部预约原因。设计稿里的旧岗位名「设计师端 / 测量员端」口播一律用现行名：家装设计顾问、家装现场顾问。推荐人收益只讲笔数与本人台账，不强调金额。

开场
装修公司要的不是又一个工具，是获客、量房、方案、交付跟在同一个人、同一套房上。家客来小程序就是这条协作链。

客户 · 服务向导
落点：服务首页。三项免费权益：免费效果图、免费家装设计顾问、免费家装现场顾问。服务票据显示真实阶段与下一步（预约 / 改期 / 档案）。Tab：服务 / 我的。

推荐人 · 推广管家
落点：推广工作台。出示推广服务码，客户扫码建档。看脱敏进度与本人收益。可加入多家企业。Tab：推广 / 进度 / 收益 / 我的。不接触手机号、精确地址、户型图。

家装设计顾问 · 方案协调者
落点：工作台。跟进待推进客户，出示活动码获客，量房资料就绪后用风格配方 AI 出图并发布给客户。Tab：工作台 / 客户 / 设计 / 收益 / 我的。

家装现场顾问 · 测量搭档
落点：工作台。连接激光测距仪，按已指派任务上门量房，毫米级户型交回设计。正式量房只从任务卡进入。Tab：工作台 / 客户 / 收益 / 我的。

企业负责人 · 调度观察员
落点：经营首页。分享活动码获客，邀请员工与推荐人入驻，看新增线索 → 已完成量房 → 已签约，优先处理异常。Tab：经营 / 客户 / 预约 / 提成 / 我的。

收束
一条链，五种身份，各做各的事。
