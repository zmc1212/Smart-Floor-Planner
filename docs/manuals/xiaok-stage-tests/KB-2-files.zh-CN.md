# KB-2 企业文件入库与结构引用手测

当前 `Limited`，对应 K-02/03/05/06/08/10。支持DOCX、文字PDF及有界XLSX；扫描OCR、复杂表图和全格式解析未交付。按[资料页](./test-materials.zh-CN.md#文件样本)准备三份可对照原件，使用独立测试文档，先完成[KB-0](./KB-0-baseline.zh-CN.md)。

## 后台实际入库

1. **KB21-01，T-A**：“企业知识 → 新建知识”，内容类型选“企业文件”，选合成DOCX，填写标题、文件名和“出处与使用许可”，点“保存草稿”。文件默认内部资料，不能据保存成功就让客户测试。
2. **KB21-02** 等解析任务结束。关闭Drawer再进“维护版本”，核对原件SHA256、任务、实际结构、表头/行列/合并及警告；点“下载当前版本原件核对”，确认是本次原件。
3. 对照将进入检索的文字，检查标题、条件、数值、单位和表注；勾选“已对照原件核对…”并“保存核对范围”。核对前不能索引/发布。只排除真正不应独立检索的块，不能认为排除行就删除其他块引用的同源表头/脚注。
4. **KB21-03** 明确把文档使用范围改为“客户可见资料”并“保存知识信息”；建立索引到就绪，再“发布此版本”。
5. 用同样流程分别导入文字PDF和XLSX，记下各自文档/版本/hash。发布版只读，原文需要修改时上传有出处的新文件版本，不用手填正文伪装原件修订。

## 小程序提问及引用核对

| 用例 | C-A原咨询问题 | 必须核对的内容 |
| --- | --- | --- |
| KB21-04 DOCX表格 | “合成材料表里样本甲在什么条件下是多少，例外是什么？” | 条件甲、2.35 mm、先核实例外；引用到正确章节/段落或表行列，不能编造Word页码 |
| KB21-05 条件区分 | “样本乙能直接用样本甲的数值吗？” | 区分条件乙及4.60 mm，不混行/漏单位；全部只作合成说明 |
| KB21-06 PDF定位 | “合成点位说明第二节如何区分方案同意和关闭？” | 原文支持，来源显示该PDF真实第2页；不能把提取文字误报成图示理解 |
| KB21-07 XLSX数值 | “合成参数表的测试比例、间距、数量分别是多少？” | 12.50%、2.35 mm、1,234与表格原值/格式一致；定位到正确工作表/行/单元格范围 |
| KB21-08 日期时刻 | “日期时间表的合成日期和时刻是什么？” | 2026-10-20、14:30，按有界完整年月日/24小时格式；不生成XLSX打印页码 |
| KB21-09 重进 | 点每份回答来源片核对文件名/真实定位/quote，退出再进同一咨询 | 原件版本和定位保持；来源有效时可回读，不串文件 |

数字必须由对应引文支持；“有引用按钮但数字来自别处”按失败。若只因模型未完成问答，分别记录“文件解析/发布成功”和“客户回答失败”，不能把两者合成通过。

## 文件失败、重试与换版

- **KB21-10 不支持内容**：用独立扫描PDF、带公式的XLSX或旧`.xls`尝试。选择器拒选、解析明确失败/警告或需OCR分别记录；不能输出伪造的完整解析。不要把OCR尚未接入记成已通过OCR识别。
- **KB21-11 关页/取消**：解析进行时关Drawer，重进看原任务；若来得及点“取消解析”，再核对取消状态。已知失败/取消可在页面提供时“重试本地解析”，当前最多3次。快速解析没来得及取消记“未触发取消”，不伪造通过。
- **KB21-12 新版本**：复制新草稿，上传改过数值且明确新版本的合成原件，重新解析/核对/索引。新稿失败不能影响有效旧版；发布后客户同题核对新值和新版本。
- **KB21-13 撤回**：撤回一份独立文件知识，客户打开旧来源、重进及重问；相关旧解释/定位不再可用。后台撤回原件下载同样应拒绝，不用旧下载链接绕过。
- **KB21-14 超限**：准备人员提供明确超4MB、超页/表范围或一条原段超必要上下文的合成文件。应有真实拒绝/失败，不静默截掉条件后发布。小文件正常不等于容量边界通过。

## 当前边界与开发配合

当前≤4MB、PDF≤50页、XLSX≤8表且每表A1:L64；字符、字节、分块和企业总量仍有上限。日期只支持明确年月日、1900/1904出处及有界24小时时刻；累计时长、区域短日期、复杂数字格式、隐藏/复杂结构仍未完整支持。健康摘要文案不能替代实际解析范围和本页核对。

重复上传的原键复用、旧租约晚到、索引外部结果未知、运行中撤回及原件权限，需要开发核查真实任务/版本/调用，不凭刷新一遍页面证明幂等。逐条登记KB21-01～14及实际未执行格式。
