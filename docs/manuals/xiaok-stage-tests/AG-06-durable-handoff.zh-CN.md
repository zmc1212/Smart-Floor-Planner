# AG-06 接待与持久执行手测

当前 `Limited`，对应 P3B/P4A→P5/P6、XK-04/07/08。检查等待、真人接管、关页重进、取消和迟到消息。先完成[共用准备](./README.zh-CN.md)，C-A与D-A使用不同账号；并发抢接额外准备第二位有接待权限的设计师 D-B。

## 请求到结束的一条完整接待

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| AG06-01 请求 | C-A在原咨询点“找设计师”或发明确找人请求 | 显示等待设计师，可继续补资料；不先强制确认摘要/提供电话 |
| AG06-02 等待补充 | C-A等待时再发文字、测试图片，退出重进 | 补充真实保存，仍在同一咨询；等待时小K不自动生成回复 |
| AG06-03 接管前后 | D-A进首页“小K咨询接管 → 待接待”，先查看请求，再“接待客户” | 接管前不露私聊原文和图片；接管后读到本次完整可用资料，显示小K暂停 |
| AG06-04 双方沟通 | D-A“对话”页回复，C-A回复；双方退出再进入 | 两边读回同一对话和真人身份，不各建一份聊天 |
| AG06-05 退出接待 | D-A“更多操作”选择退出本次接待，再查看队列；C-A观察 | 回到等待状态，原文保留；原接待人失去本次服务访问，不虚报客户已结束 |
| AG06-06 客户结束 | 再接手后，C-A点“结束接续，回到小K”，发送普通问题 | 恢复AI；D-A不能继续读取/回复本次私聊 |
| AG06-07 取消等待 | 新建等待请求，未接手时C-A点“取消等待，回到小K” | 同一咨询恢复AI，不残留可抢接请求 |

员工动作名称以“更多操作”中实际列出的选项为准；不要把“退出接待”和客户“结束接续”当成相同状态。

## 并发、关页与事件

1. **AG06-08 抢接**：D-A/D-B同时打开一条待接待请求，先后快速点“接待客户”。仅一人成功；另一人得到状态更新/冲突，不能同时获取有效接待访问。
2. **AG06-09 生成中停止/转人**：AI生成时点“停止回答”，待状态明确后请求设计师。真人接手后即使原模型晚到，也不能插入迟到AI回复。若未能稳定复现迟到，仅记录已测步骤，服务侧另核对。
3. **AG06-10 离页后继续**：客户发送问题后返回首页，再进原咨询。原消息和原运行状态应恢复，不另生一条客户消息。手机断网不代表后台Worker停机。
4. **AG06-11 真人期间团队回传**：客户进入真人接待；M-A在工地聊天回传一条独立事项结果。客户恢复AI后，只有仍有效的当前事件回到原咨询，不重复投递、不选第二咨询。
5. **AG06-12 接待人停用**：管理员在合成环境停用当前接待人，C-A重进。应显示接待人暂不可用，不能虚报已结束；客户可结束接续回小K，旧员工不能继续读写。

## 需要开发配合的故障

Worker进程重启、租约丢失、双Worker竞争、工具已提交但checkpoint未保存、回复已提交但未投递、未知供应商调用及乱序事件，都不能靠关闭小程序证明。请开发用既有隔离验收入口分别核对原run/job/step/outbox与用量；不为本页停止共享开发服务或重放历史未知任务。

本页记录AG06-01～12，未执行的并发/停用或受控故障独立标注。跨天通用接续仍为剩余范围。维护依据：[二期合同](../../xiaok-assistant-phase-2.zh-CN.md)的 P2S 接待、P4A 回传及持久执行合同；客户端为现有 C01/S01/U01。
