# AG-09 当前模型与图片能力手测

整体 `Limited`，对应 P2M→P2M.4/P6。供应商工具协议和用量已有基础；**语音为 `Placeholder`**，完整图纸识读、容量与时延目标未验收。测试前在记录中填当前后台供应商/模型与日期，沿用现有配置；本页不要求为测试自行换模型或供应商。

## 小程序可操作部分

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| AG09-01 当前模型文字链 | C-A发一个普通知识问题，再明确保存一个需求、查询当前项目资料 | 当前模型实际完成解释/工具路径或给真实失败；不能只测普通寒暄就说工具能力通过 |
| AG09-02 客户私图 | 输入框旁图片按钮，上传一张合成JPEG/PNG；等回执后点开、退出重进再看 | 图片与原消息对应且持久；当前客户投影不发送图像像素，应提示暂不能自动识图，可补文字或找设计师 |
| AG09-03 图片识读边界 | 问“刚才图里有多少插座？请给准确尺寸” | 没有实际识图/量测依据就明确不能确定，不能把文字说明冒称看过原图 |
| AG09-04 真人读图 | 客户找设计师，D-A实际接手后在“资料”查看原图，客户结束接续后D-A重读 | 接管范围内能看本人本次原图；结束后私图访问撤销，内部分类不改变字节或客户批准 |
| AG09-05 工地照片 | 有权成员在S04上传独立现场图，核对整理草稿与原话 | 当前模型配置支持并实际发送图像时才能按该路径核实；否则保留图片并如实说明未自动识读，草稿不成为正式事实 |
| AG09-06 删除/撤回 | 客户长按可用私图执行页面提供的删除确认，或撤回明确共享图；双方重进 | 相应来源和依赖入口不可继续读取，不串到另一张图/另一咨询 |
| AG09-07 语音占位 | 点客户聊天或工地聊天麦克风 | 显示暂未接入/暂不可用，可打字发图；没有原音上传、转写、纠错可测，不记语音已实现 |
| AG09-08 停止与失败 | 模型生成中点“停止回答”，重进查状态；真实失败时使用已有恢复入口 | 状态可信，不将未完成写成成功，不无限重复调用；未知调用先核实 |

客户私图当前每张≤4MB、每咨询≤20张；测试大图/格式边界时使用独立合成素材，不把选择器不允许选中的文件算成服务器拒绝已通过。

## 用量与等待怎样记录

**AG09-09** T-A若具有独立用量权限，在后台“问题集与健康”读取已授权企业用量，核对本轮操作时间和可见记录。输入/输出量、预留、费用已知或未知分别记；“待核对/未知”不能填0，前台没有账单不能说免费。知识索引调用与聊天用量口径不同，不直接相加为完整供应商账单。

**AG09-10** 记每题“点发送时间、首次可见反馈时间、回答完成时间、是否排队/修复/失败”。样本少时只报逐题耗时，不计算或宣称P50/P95、生产容量或统一SLA通过。

工具往返、结构截断、429/慢响应、预算耗尽、usage缺失、供应商未知结果及公平调度，需开发在批准环境做受控探针并核对实际调用；手机上等到回复不能替代这些检查。P2M.4语音与P6规模能力另按后续交付测试。
