# KB-4 问题缺口与知识回归手测

当前 `Limited`，对应 K-06/10/11及受影响回归。运营功能在后台“小 K 知识库 → 问题集与健康”，**没有小程序批量管理页**。本阶段仍需回小程序验证修订后的真实客户回答，后台保守摘录回归不能替代它。

先完成[KB-0/KB-1](./KB-0-baseline.zh-CN.md)，确保K-A当前有效、客户可见、索引就绪；T-A具备知识管理权，读取聊天用量另需原有独立权限。

## 建两道固定题并复跑

1. **KB41-01，T-A后台**点“新增问题/缺口”：名称“合成手测书房说明”，固定问法“书房长期用屏幕，靠窗时应先了解什么？”，预期“应有依据回答”，必需来源选择本轮K-A；禁止来源可选本企业K-I内部资料。核对重点写“采光与习惯；不能编造现场尺寸或批准”。保存。
2. 再建“合成手测资料不足题”，问“没有量测记录时，能给出我家书房已经量出的宽度吗？”，预期“应明确依据不足”，填清不得编造实际量测的检查重点。此题不应被当成正向知识覆盖率。
3. **KB41-02** 对第一题点“复跑同题”，在“同题回归与缺口核对”读取原run状态、召回/入选/引用结构检查和实际回答。需要时点“打开本人原试问与引用/检索诊断”。对第二题同样操作。
4. **KB41-03** 来源结构通过后，人工读回答：含义正确、条件完整才填写明确核对备注并“确认本版核对通过”；若仍有问题，写原因并“保留缺口”。不能因为绿色结构提示就直接认定专业正确。
5. 关闭Drawer、刷新浏览器再进题目，打开**原次结果**。题目与共享备注保留，回归历史仍指向本次原试问，不创建一份新模型调用。

**预期**：题目属于企业共享运营资料，试问和执行结果仅本人私有。客户私聊不会自动复制到题库；保存题目/执行回归不建施工事项或企业规则。

## 有界批量与原键恢复

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| KB41-04 批量完成 | 选中两道就绪问题，点“批量复跑选中问题”，填批次名，并发先选1，“保存并执行” | 显示真实批次/逐题状态；每批1～20题、并发1～3，完成不等于每题正确 |
| KB41-05 关页重进 | 创建后关Drawer/离开页面，再回本页“刷新批次”，打开同批 | 后台Worker继续原任务，能查看原次结果，不重复创建批次/题目 |
| KB41-06 取消 | 对独立新批次在仍执行时点“取消本批后续执行” | 未派发题不再开始；已完成题保留当前获权记录；晚到结果不复活已取消任务。若全跑完才点击则取消路径未测 |
| KB41-07 恢复 | 实际出现blocked/回执待核对时，使用“用原键恢复本批”或页面原结果核对入口 | 恢复同一批/原执行，不重发未知供应商调用；没出现可恢复状态记未触发 |

不要靠多点“保存并执行”尝试触发恢复；真实丢回包和局部派发失败的幂等性需开发受控核实。

## 修订失效及小程序同题

1. **KB41-08** 修改第一题固定问法并保存，旧题修订结果应收起/失效；按当前修订复跑。不要拿旧结果核对新版题。
2. **KB41-09** 为K-A建新草稿，修改一条明确合成说明，重新索引发布。旧核对/诊断/批次按来源与epoch变化失效或待复验；不能把旧通过保留为当前版通过。
3. **C-A小程序**，在甲屋原咨询用修订后的同题提问，点来源看新版，再退出重进。检查生成式解释仍有据；这一步单独记录为 **KB41-10**，不能引用后台批次结论代替。
4. 撤回这份独立测试资料，再读旧回归/客户来源与回答；旧正文/核对不能继续有效。恢复须以新的合法发布版复验。

## 权限、健康和未实现范围

**KB41-11** 换另一名有权限管理员：能看到企业共享题目/缺口，不能看到T-A私有试问/执行正文。选定企业的admin/super_admin继承管理权；普通员工/客户和另一企业不开放本企业运营数据。

**KB41-12** 读取健康：核对队列、资料/profile、就绪/失败状态；有独立用量权限时点“读取已授权企业用量”。未知费用保持未知，未决预留不能抹成0；健康计数不证明外部供应商实时连通。日期/文件实际支持范围按[KB-2](./KB-2-files.zh-CN.md)和解析结果核对。

当前企业≤100题/2,000次回归，来源选项最多200份；这些是实现上限，不是生产容量实测。定时计划、影子profile重建/切换/回滚、大规模容量和全部文件格式仍未交付，不在小程序寻找入口，也不把批量完成当这些能力通过。

KB41-01～12逐条记录，来源结构、专业判断、执行失败、取消、费用未知分别填写。维护依据：[知识计划](../../xiaok-enterprise-knowledge-plan.zh-CN.md)、[二期合同](../../xiaok-assistant-phase-2.zh-CN.md)的KB-4运营核心和有界批量合同。
