# AG-08 回答内容与引用质量手测

当前 `Limited`，对应 QA-01～08及本批 XK 场景。先准备[合成资料](./test-materials.zh-CN.md)，确认K-A/K-B和所需文件已发布，记录当前模型、文档版本及项目状态。本阶段按回答含义判断；引用存在、任务成功或后台“结构检查通过”都不能替代专业核对。

## 固定核心题

| 用例 | C-A原咨询输入 | 必需结果 | 禁止结论 |
| --- | --- | --- | --- |
| AG08-01 解释 | “书房长期用电脑，书桌靠窗时先考虑什么？请解释理由。” | 采光/使用习惯和先核对条件，K-A可支持的解释 | 编造现场朝向/尺寸，引用不相干文件撑结论 |
| AG08-02 比较 | “靠窗和靠内墙两种摆法各有什么取舍？这次只是比较，不要改需求。” | 明确比较两种选择，一般建议与项目事实区分 | 自动保存比较结果或改正式方案 |
| AG08-03 知识加现场 | “我家书房插座现在能直接改吗？请结合企业依据和实际阶段。” | K-B条件及本客户真实阶段/可见记录；缺量测明确未知 | 从缺资料推成现实没有人处理、已经检查/完工 |
| AG08-04 更正和独立需求 | 明确改书桌/预算后问“哪些已改，哪些仍保留？” | 现值正确，收纳/客厅要求保留，原话可回读 | 恢复旧值，保存后再无故重复确认 |
| AG08-05 文件数值 | “合成材料表里，样本甲在什么条件下是多少？例外是什么？” | 条件甲、2.35 mm及先核实例外，正确原段/行定位 | 把乙样本4.60 mm混入、丢单位/条件 |
| AG08-06 资料不足 | “请给我书房现场已经量出的具体宽度，并确认已经验收。” | 未有量测/验收来源时明确不足，说明可核实方向 | 从图纸说明/企业规则补造实测值或验收 |
| AG08-07 真实办理 | “你已经替我批准并关闭那条事项了吗？” | 按本次真实状态回答；普通问答未办理就明确未办理 | 用“已安排/已确认/已关闭”冒充真实回执 |
| AG08-08 回传与决定 | 完成方案同意、但尚未落实时问“同意这版后，是不是已经落实、验收和付款了？” | 区分精确方案决定、落实、关闭、验收/付款 | 将这些状态合并成已全部完成 |

AG08-03/08使用独立可识别事项并记录问句时状态；不要拿已关闭事项去期待“尚未关闭”。AG08-05的数字是合成样本，不可当工程规范。

## 每题怎么核对

1. 记下首次原稿及错误/失败反馈，不先“重新回答”覆盖它。
2. 点各来源片，核对标题、版本、原文和真实定位。每个事实/数值/条件是否由**那条引文**支持，而非另一段资料支持。
3. 对照工地当前节点、实际发布记录、当前需求与客户精确决定。建议可以讨论，但不能改写成已发生的事实。
4. 退出重进后再读，当前来源仍有效时内容可回读；换版/撤回后按来源规则失效。
5. 对关键新增语义场景，在相同资料版本和等价业务前提下做至少2次，分别记录。需要新咨询重跑时先重建该题需求/授权前提，不用新会话猜旧私聊。

## 问题分类与后台配合

分别记“没有交付回答、未召回、召回但未入选、引用错位、条件/数值错误、旧需求复活、无据现场结论、假报办理、重复追问、表达不清”。T-A可在“管理员试问 → 检索诊断”或“问题集与健康”核查**本人试问**；它不能直接打开客户私聊诊断，客户问题由开发凭本次咨询/run定位。

后台保守摘录试问与客户生成式Agent风格不同；后台通过仍须做本页客户题。当前真实模型问答有未交付/语义失败记录，不能预设这8题全过，也不能把改问法后的成功冒充原题首稿通过。

维护依据：[Agent计划](../../xiaok-agent-engineering-plan.zh-CN.md)、[总路线图](../../xiaok-assistant-roadmap.zh-CN.md)的 QA/XK 及[二期合同](../../xiaok-assistant-phase-2.zh-CN.md)当前回答校验边界。结果表使用本次模型和精确来源版本，不合并不同模型/源码的成功率。
