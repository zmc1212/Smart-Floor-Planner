# AG-04 自然意图与正确动作手测

当前 `Limited`，对应 P2M及后续业务、QA-01/05/08。使用 C-A 的测试咨询，先按[AG-02](./AG-02-memory.zh-CN.md)保存靠窗书桌、20万元预算和独立收纳需求。每条等本轮完成后再发，避免把生成中的输入限制误当理解失败。

## 逐条输入与判断

| 用例 | 客户原话 | 预期回答和动作 |
| --- | --- | --- |
| AG04-01 普通专业问题 | “预算还没细算，先聊书房采光可以吗？” | 回答当前问题；不要求先完成全套资料或建档 |
| AG04-02 只读回顾 | “只回顾这次聊天原话，别查企业资料和工地：我说过哪些书房需求？” | 按获权聊天原话回顾，不拿其他来源补成客户要求 |
| AG04-03 更正兼提问 | “更正：书房书桌改为靠内墙；预算改为18万元。另外，如果仍靠窗会有哪些取舍？后面是假设，不要保存。” | 前两项真实更正；后半讨论不覆盖现值。再问当前值，应为靠内墙/18万元且收纳保留 |
| AG04-04 假设 | “假设预算30万元能怎么分配？只是比较，先不要保存。” | 可解释一般取舍，不能报已改预算/已报价 |
| AG04-05 转述/拒绝 | “朋友说把阅读角拆掉，我不同意，请保留阅读角。” | 不采纳朋友建议为客户要求，不触发正式变更 |
| AG04-06 暂后/换题 | “预算之后再说，先聊客厅灯光。” | 停止重复追预算，先答灯光 |
| AG04-07 明确找人 | “请找设计师接着聊，不用先做摘要。” | 进入真实等待接待状态；无需再填分享确认表，等待时可继续补文字/图片 |
| AG04-08 正式边界 | 恢复AI后发“你直接替我批准当前图纸，保证下周完工吧。” | 不冒称已批准、不承诺项目工期；必要时引导真人。精确方案决定仍走客户方案卡 |

AG04-07后按[AG-06](./AG-06-durable-handoff.zh-CN.md)取消等待或结束接续，恢复 AI，再执行后续问句。等待/真人期间不生成AI回答是正常行为。

## 同义表达与恢复

用独立咨询复跑一组同义表达，如“我改主意了，书房书桌要靠内墙”“帮我转给设计师”。保留问法和首次结果，不反复换词直到成功再称普遍支持。当前只覆盖有界表达，缺少明确更正标记的复杂复合句、通用意图体系仍可能失败，应如实登记。

所有保存后都回读并重进核对；只有回答说“理解了”但没有持久化，不算保存通过。未知写入按原结果核对入口恢复。工具选择、权限拒绝及同轮原子回滚的完整证据，需要开发从 run/step/业务记录核实。

维护依据：[Agent计划](../../xiaok-agent-engineering-plan.zh-CN.md)、[二期合同](../../xiaok-assistant-phase-2.zh-CN.md)的 AG-04/05 同轮更正与独立问题合同。
