# KB-1 专业知识与检索诊断手测

当前 `Limited`，对应 K-01/04/06/07/08/09/11和P2M.1～.3。后台负责维护/发布，小程序负责客户问答、来源与重进；不存在小程序知识管理页。使用[合成资料](./test-materials.zh-CN.md)，先完成[KB-0](./KB-0-baseline.zh-CN.md)。

## 从草稿到客户可用

1. **KB11-01，T-A后台**：选E-A，“小 K 知识库 → 企业知识 → 新建知识”，输入K-A，选择“服务说明/客户可见资料”，展开专业字段，按资料页填类型、主题、出处、版本、实际章节和审校备注，点“保存草稿”。
2. **C-A小程序**：在甲屋原咨询问“合成手测书房使用说明有哪些内容？”草稿不得进入客户引用，其他已发布资料可独立回答；不能因有回答就认定泄露了草稿。
3. **KB11-02，T-A**：在“维护版本”建立索引，等待“索引就绪”。可用该草稿的“试问此草稿”入口做明确草稿范围的本人预览；随后“发布此版本”并确认。
4. **C-A** 再问“书房长期用屏幕，靠窗布置要先考虑什么？”点来源片核对K-A精确版本及引文。追问“缺现场尺寸可以直接定点位吗？”不应编造实际值或批准。
5. **KB11-03**：退出小程序，从“查看历史”重进原咨询，回读问题、回答和来源。

**完成标准**：保存、索引、发布各自有真实状态/反馈；客户只用当前有效发布版本，专业条件/前置/例外没有被吞掉。FAQ可按同链路另建一份问答复验，不能把正文和FAQ当两套权限。

## 条件、词形与明确冲突

| 用例 | 准备与客户提问 | 预期 |
| --- | --- | --- |
| KB11-04 实际阶段 | 建K-B独立副本，添加“实际阶段（节点key）→仅适用这些值→utilities”，索引发布；C-A水电、C-B泥木分别问这条流程是否适用 | 按本人绑定的唯一获权项目真实阶段解释；泥木不能套水电条目作为当前指令 |
| KB11-05 条件未知 | 独立条目登记材料/型号或城市条件，客户仅在问题里提到型号，不提供实际核验来源 | 当前材料/城市仍未知，不因为模型读到关键词就确认实际匹配；一般说明仍可讨论 |
| KB11-06 有界同义词 | 另建合成条目明确写“瓷砖胶/粘结剂”主题，不写工程等级结论；分别问“黏结剂”和“粘合剂”的合成说明 | 可测试登记词形召回；不能由检索同义扩展推断材料工程等效。通用词库并未完成 |
| KB11-07 明确冲突 | 按资料页发布相同规则主题、不同明确口径的冲突甲/乙；问当前该采用哪种 | 保留两份依据并提示待核实，不凭高分或上传较晚自行裁定；测完撤回冲突样本 |

结构条件填写实际节点 **key**，不能用显示名称“水电”代替 `utilities`。房间、材料/型号、城市当前不会自动从问句确定；`applicable`也不等于所有前置检查已完成。自由文本任意冲突识别尚未交付。

## 换版、受众与撤回

1. **KB11-08** T-A由当前发布版“复制为新草稿”，明确改一条合成说明；未发布/索引失败时客户仍用有效旧版，不能提前用新稿。
2. 新版就绪并发布后，客户同题再问，核对当前版本。旧回答/引文是否可用由当前来源规则处理，不能让旧版继续充当现行规则。
3. 用独立资料测试未来生效/已过期：未来稿不能提前替换现行有效依据，过期版本不能参与当前检索；不要求尚未交付的定时切换服务。
4. **KB11-09** 把独立测试资料从客户可见改内部，或撤回整份知识；客户点旧来源并重进/重问。相关回答/引文应失效，不读出内部内容。另一企业同主题资料也不能进入。

## 后台诊断配合

**KB11-10，T-A** “管理员试问 → 新建试问”，选客户范围并问固定问题；在本轮回答旁打开“检索诊断”。核对实际查询、候选来源版本、入选/未入选、条件缺项与引用，不把相似分数当正确率。可在本人试问明确选择草稿范围；它不开放草稿给客户。

换成另一管理者，不能读取T-A的私有试问/诊断；平台admin/super_admin选定企业可管理知识，但仍不继承别人的试问。撤回来源后，旧诊断不能继续返回正文。后台摘录试问通过后仍要完成客户问答题。

逐条记录KB11-01～10。未知费用、没召回、低排名、条件未知、模型执行失败分别记。自动条件抽取、通用语义冲突和完整专业客服仍是剩余范围。维护依据：[知识计划](../../xiaok-enterprise-knowledge-plan.zh-CN.md)及[二期合同](../../xiaok-assistant-phase-2.zh-CN.md)的KB-1当前合同。
