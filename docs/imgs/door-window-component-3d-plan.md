# 门窗构件 3D 编辑本地原型实现计划

## Summary

- 在 `miniprogram/pages/surveying-editor/surveying-editor` 中，用户点墙上的“门/窗”后，先仍留在 2D 平面图中显示并选中门窗；选中门窗后点击侧边“编辑”才进入独立的“构件编辑”3D 场景。
- 第一版采用“本地原型”范围：内置程序化门窗模型、少量本地缩略图/分类，不接真实素材库，不写正式 floor plan，不影响旧版 `editor.*`。
- 受影响的旧版完成模块：无。此次只扩展新版 `surveying-editor` 原型；不触碰旧版测量、BLE、正式保存、导出/report、测量日志或旧版 3D。

## Key Changes

- 入口与状态：
  - `addPrototypeOpening('door'|'window')` 创建并选中门窗后，仍停留在 2D 平面图中显示门窗符号。
  - 选中已有门窗后，点击侧边对象工具的“编辑”进入 3D 构件编辑场景。
  - 返回按钮关闭构件编辑并回到 2D 测绘画布，保留选中对象。
- 3D 场景：
  - 在页面 WXML 增加 `canvas type="webgl"`，仅构件编辑时整屏显示。
  - 使用 `threejs-miniprogram` 初始化独立 Three.js 场景：地台、单面墙体、墙洞、选中门/窗模型、红色尺寸辅助线。
  - 3D 构件编辑顶部复用 `navigationSafeTop` 预留安全区，返回箭头必须在状态栏/胶囊按钮下方清晰可见。
  - 墙体、地台、门板、窗框、玻璃使用明显区分的本地材质；墙体保持浅灰白，门偏暖木色，窗框深色且玻璃半透明浅蓝。
  - 默认视角朝向门窗模型所在正面；切换长度/宽度/高度/距地/边距等规格 tab 时，只更新标注线和模型，不把相机重置到墙体背面。
  - 红色尺寸辅助线在墙体前后两面同时绘制，并放到模型外侧，避免被门板、窗框或玻璃遮挡。
  - 支持单指旋转、双指缩放/平移，默认视角类似参考图的斜视墙面。
  - 3D 场景从当前 `floor.walls/openings/session.selectedOpeningId` 读取数据，尺寸更新后实时重绘。
- 门窗数据：
  - 在现有 opening 字段基础上扩展本地原型属性：`modelId`、`modelCategory`、`materialId`、`depthMm`、`entryDoor`。
  - `length` 对应 `widthMm`；`height` 对应 `heightMm`；`距地` 对应 `sillHeightMm`；`边距1/边距2` 根据 `wall.lengthMm`、`centerOffsetMm`、`widthMm` 互相换算。
  - `宽度` 对应构件/墙厚方向深度，默认取当前墙厚；提供“同步更改墙体厚度”开关，开启时同步调用墙厚更新。
- 编辑面板：
  - 下半屏实现三组主操作：规格、翻转、模型/材质。
  - 规格页包含 tabs：长度、宽度、高度、距地、边距1、边距2；点击规格 tab 直接弹出大数字输入层，输入过程实时同步 3D 标注、模型尺寸、2D opening 和本地草稿。
  - 构件规格输入层复用现有大数字键盘；在 `component*` 输入模式下，数字键、退格、清空会即时更新当前门窗，确认按钮只关闭输入层。
  - 构件规格实时输入为空时只清空输入显示，不提交尺寸；输入非法或超出墙长时保留上一次有效 opening，并显示校验提示。
  - 实时输入仅作用于 3D 构件规格页；普通墙长、墙厚和旧 2D 门窗宽高距地输入仍保持“确认后提交”。
  - 翻转页对门支持内开/外开切换；窗显示固定或禁用提示。
  - 模型页提供门/窗分类 chips、公共库下拉占位、本地缩略图网格、选中角标；更换模型只更新 `modelId/modelCategory/materialId` 和本地预览，不接远程库。
  - 门类型额外显示“设为入户门”浮动按钮，切换 `entryDoor`，同一楼层只允许一个入户门。
- 文档同步：
  - 更新 `docs/surveying-module/roadmap-and-acceptance.md`，把 Phase 8 门窗构件从 Deferred 细化为本地原型实现范围。
  - 更新对应中文/配套文档若存在同名 zh-CN 版本；保持“原型不写正式数据”的边界说明。

## Test Plan

- 新增门：选中墙体点“门”，仍留在 2D 平面图中显示并选中门；点侧边“编辑”后进入整屏 3D 构件编辑，默认单开门宽 900、高 2100、距地 0、墙厚方向宽度取墙厚。
- 新增窗：点“窗”，仍留在 2D 平面图中显示并选中窗；点侧边“编辑”后进入整屏 3D 构件编辑，默认平开窗宽 1500、高 1500、距地 900。
- 尺寸编辑：切换长度/高度/距地/边距1/边距2，输入数值后 3D 红线、2D opening 位置和本地草稿同步更新。
- 输入交互：点击任一规格 tab 后无需再点数值行，直接出现大数字输入层；按数字、退格或清空时，有效数值实时更新构件尺寸，确认按钮只关闭输入层。
- 实时输入边界：构件规格输入框清空时不提交 0；输入超出墙长的边距或非法尺寸时，opening 保持最后一次有效状态，页面显示校验提示。
- 输入隔离：在普通测墙、墙厚、2D 门窗宽高距地输入中，仍需点击确认才提交，不能被构件实时输入逻辑影响。
- 视觉检查：进入 3D 构件编辑后，顶部返回箭头在安全区下方可见；门/窗与墙体颜色明显区分；不旋转视角时能看到至少一侧红色标注线，旋转到背面也能看到对应标注线，且标注线不被模型遮挡。
- 视角检查：连续切换长度/宽度/高度/距地/边距1/边距2时，相机保留当前旋转和缩放；关闭 3D 后重新进入同一门窗时恢复默认正面斜视角。
- 边距换算：修改边距1或边距2后，`centerOffsetMm` 正确变化，且 opening 不超出墙长。
- 模型选择：切换门窗分类和缩略图，选中态、3D 外观、本地草稿恢复一致。
- 返回与恢复：关闭 3D 编辑回到 2D；保存原型草稿、退出、重进后门窗尺寸和模型选择恢复。
- 边界：未选墙时不能新增门窗；删除墙时仍删除其门窗；旧版 `pages/editor/editor` 行为不变。

## Assumptions

- 第一版只做本地原型构件库，不接真实远程模型库。
- 门窗 3D 模型使用程序化几何体和本地缩略图占位，后续可替换为真实 GLTF/纹理资源。
- 新版 `surveying-editor` 继续只保存到 `surveying_prototype_draft_v1`，不写正式户型、CAD、报告、测量日志或旧版草稿。
