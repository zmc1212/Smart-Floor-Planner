# 装修服务小程序内测手册

给所有参加内测的同事。不要求互联网背景，会用微信、会打开电脑网页即可。

账号、测试用的网页地址、该进哪家装修公司，由组织这次内测的人发给你。本手册没有密码。

---

## 你今天要做什么

我们在测一套给装修公司用的工具：

1. 有人介绍客户，或员工自己在外面发码
2. 客户用微信领免费上门量房和设计
3. 约时间上门、量房子、出效果图、签单
4. 公司记账：该给介绍人、设计师、测量员多少提成（钱在线下发，系统只记账）

你的任务不是找理论问题，而是：**按下面步骤点一遍，看实际好不好用。**  
每做完一步，打勾。和手册写的不一样，就截一张整屏图发到群里。

## 这些词是什么意思

| 手册里会写到 | 平常可以当成 |
| --- | --- |
| 后台 | 电脑浏览器打开的管理网页，不是小程序 |
| 小程序 | 手机微信里打开的这个应用 |
| 入驻 | 第一次扫公司的码，加入这家装修公司 |
| 授权手机号 | 微信弹出「允许使用手机号」，点允许 |
| 介绍人 / 推荐人 | 把客户介绍给装修公司的人，比如小区业主、合作伙伴 |
| 推广服务码 | 介绍人出示给客户扫的二维码（画面上不要出现公司名，这是故意的） |
| 活动码 | 设计师或测量员自己出示给客户扫的码（可以出现公司名） |
| 这个客户 / 这一单 | 系统里这份服务记录。开发有时叫「线索」，你把它当成「这一户人家的服务单」就行 |
| 当前进度 | 屏幕上写的「已预约」「已过期」「方案已发布」等。请看这行字，不要只看「量房中」三个字 |
| 自动安排 | 客户领完服务后，系统自己指定设计师和测量员，不用抢单 |
| 提成台账 | 签单后系统记下该付给谁多少钱。不是微信转账 |
| 底部那一排 | 手机屏幕最底下的几个按钮，例如「服务」「我的」 |

## 先听一个完整故事

**朋友介绍这一路（必测）**

小区业主老周加入装修公司 → 打开自己的推广码给李女士扫 → 李女士用微信手机号领取 → 系统自动安排设计师小美、测量员阿强 → 约上门时间 → 阿强上门量房 → 小美做效果图并发布给客户看 → 签单 → 系统记下老周、小美、阿强三笔提成。

**员工自己发码这一路（也要测）**

小美或阿强在小区出示「活动码」→ 王先生扫码领取 → 后面量房、出图、签单一样 → 只给设计师和测量员记提成，**没有**介绍人那一笔 → 老周的「进度 / 收益」里也看不到这一单。

同一个客户如果已经有进行中的服务，再扫别的码 **不会** 换成另一家公司。所以王先生必须是另一个微信，不能和李女士用同一个。

## 手机底下应该出现什么

用对应身份登录后，看屏幕最底下。对不上就先截图问组织者。

| 你现在是 | 底下应有 | 打开后首先应看到 |
| --- | --- | --- |
| 客户 | 服务、我的 | 当前进度、预约说明、**一个**下一步按钮 |
| 介绍人 | 推广、进度、收益、我的 | 先选公司，再出示这个公司的推广码 |
| 设计师 | 工作台、客户、设计、收益、我的 | 自己负责的客户；过期没重新约的应能看到；「收益」看自己的提成 |
| 测量员 | 工作台、客户、收益、我的 | 今天的任务；从工作台进「日程」；量房只能从任务点进去；「收益」看自己的提成 |
| 老板 | 经营、客户、预约、提成、我的 | 「经营」里是需要处理的异常；「提成」是全公司应付台账，线下打完款后可点「已线下打款」 |

右上角小红点数字来自真实待办。如果加载失败，应写「暂时无法读取」，**不应变成 0 让你以为没事**。

点「我的」，应能看到自己现在是什么身份、哪家公司。有多个身份时可以切换；只有一个身份时，不必出现让人去「切换」的假入口。

## 第一部分：开张前（张总用电脑做）

用电脑浏览器打开组织者给的后台地址，登录。

左侧找到 **推荐网络 → 运营工作台**。这一页只会告诉你「现在准备好了没有」，**不会自动造出客户和订单**。下面各项都变绿（或显示已就绪）再开始让客户扫码。

按这个清单做：

1. **推荐网络 → 入驻码**  
   分别查看或下载两张码：  
   - **员工入驻码**：给小美、阿强扫，加入公司当员工  
   - **介绍人入驻码**：给老周扫，加入当介绍人  
   两张码不能混用。换新码之后，旧码应立刻扫不了。

2. **员工管理**  
   - 小美：账号是启用的；没有打开「暂停自动派单」；已填写微信号；已上传她的个人微信二维码（客户加她微信用）  
   - 阿强：账号启用；没有暂停自动派单（测量员可以不上传二维码）  
   小美也可以自己在手机「我的」里补微信号和二维码。补全后，新客户领取时应能排到她。

3. **推荐网络 → 预约设置**  
   点一次 **保存并确认预约规则**。  
   常用默认：每天上午 9 点到下午 6 点、每次量房 2 小时、半小时一格、最多约 30 天内、客户最晚在开始前 2 小时改时间。

4. **三方提成**  
   介绍人、设计师、测量员三条规则都打开。  
   如果某条是「按合同金额百分比」，签单时必须填写大于 0 的合同金额。

5. 回到运营工作台，确认「小程序码能生成」是好的。打不开码图，先找组织者，不要开始扫码测试。

做完请打勾：

- [ ] 两张入驻码都能打开
- [ ] 小美资料齐全且未暂停
- [ ] 阿强未暂停
- [ ] 预约规则已保存确认
- [ ] 三条提成都启用

## 第二部分：入职（用手机微信）

请用**自己的手机微信**扫码，不要用别人已经登录过的号。

### 2.1 小美、阿强加入公司

1. 张总把 **员工入驻码** 发到群里或打印出来。
2. 小美扫码 → 允许使用手机号 → 选择 **设计师**。
3. 阿强扫码 → 允许使用手机号 → 选择 **测量员**。
4. 小美打开「我的」（或请张总在员工管理里），填好微信号，上传个人微信二维码。

应出现：马上可以使用，不用等待审核。  
不应出现：扫介绍人的码却能当员工，或反过来。系统应明确说不行。

- [ ] 小美已是设计师，资料齐全
- [ ] 阿强已是测量员

### 2.2 老周加入当介绍人

1. 张总出示 **介绍人入驻码**（不是员工码，也不是以后给客户看的推广码）。
2. 老周扫码 → 允许使用手机号 → **填写真实姓名**（不要空着）。
3. 进入底部「推广」→ 选中这家公司 → 打开推广服务码，准备给李女士看。

应出现：

- 给客户看的这张码上 **没有** 装修公司名字、没有公司 Logo、不能选公司。这是保护介绍人的规则，不是漏做。
- 张总在后台 **推荐网络 → 推荐人** 里能看到老周的姓名和手机号。

- [ ] 老周能出示推广码
- [ ] 给客户看的画面上没有公司名

## 第三部分：朋友介绍这一单（李女士，必测）

按顺序做。上一步不对，先停下来截图。

### 3.1 李女士领取服务

1. 李女士用微信扫描老周刚打开的 **推广服务码**。
2. 应先看到免费上门测量、设计师服务的说明，再请她点微信手机号授权。
3. 成功后应看到设计师 **姓名、微信号、个人二维码**（方便加微信）。

应出现：

- 只扫码、还没点允许手机号时，张总后台里 **还没有** 这一单。点允许之后才建档。
- 成功页只有设计师个人微信，**没有** 公司名。
- 张总打开 **线索转化**，能看到李女士这一单；人员齐全时进度为「已匹配测量员」，缺人则为「待派单」。

不应出现：领取说明里出现装修公司名或让客户选公司。

- [ ] 授权后才出现这一单
- [ ] 李女士拿到小美的微信资料
- [ ] 领取页没有公司名

### 3.2 系统有没有自动安排人

张总在 **线索转化** 点开李女士。

人员齐全时应看到：已指定小美、已指定阿强；小美、阿强手机工作台都能看到李女士。

**另外做一次「公司没人」**（可用另一个测试客户，或先暂停小美）：

1. 在员工管理把小美或阿强打开「暂停自动派单」，或先不给小美传二维码。
2. 再让一个新客户领取。
3. 这一单应停在「待派单」；张总手机「经营」里应能看到需要处理。
4. 把人补齐或取消暂停后，在线索转化里点 **重试派单**。
5. 应能排上人，进度变为「已匹配测量员」。

- [ ] 正常情况能自动排到小美和阿强
- [ ] 缺人时会停住，补人后能重试成功

### 3.3 约上门时间

李女士打开「服务」，下一步应是去预约。小美也可以代她约。  
**只能有一个有效预约**：谁先约成功算谁的，后约的人应提示已经约过了。

填写上门地址（可以手写楼栋门牌，也可以用微信选地点），再选系统给出的时间格子。

应出现：

- 只能选上班时间内、还没被占用的时间。
- 李女士、小美、阿强、张总电脑上看到的是同一趟上门。
- 阿强日程里如果已经存了地图位置，应能一键打开微信地图导航。
- 老周打开「进度」，能看到大概到哪一步了（例如已预约），但 **不能** 看到李女士手机号和精确门牌。

- [ ] 约上了，四方看到同一时间
- [ ] 老周看不到手机号和门牌

### 3.4 李女士改时间

在上门开始前 2 小时以上（具体以预约设置里的小时数为准），李女士打开预约，改到另一个还能选的时间。

应出现：马上改成功，旧时间空出来。  
如果原阿强那个新时间没空，系统可以自动改派别的测量员（仅「朋友介绍」这一路）。

上门前不到 2 小时：李女士不能再改，界面也不应假装还能改。这时只能小美或张总填写原因后改。

李女士 **没有** 「取消预约」按钮。取消只能小美或张总做。

- [ ] 提前足够时可改期
- [ ] 太近了客户改不了
- [ ] 客户不能自己取消

### 3.5 阿强上门量房

1. 到了预约开始时间，进度应为「上门量房中」。
2. 阿强从工作台里 **李女士这一条任务** 进入量房（只有这里能进，不要在别的菜单找）。
3. 画出完整房间并提交。
4. 回到预约页，点「确认完成量房」。

应出现：

- 还没提交合格户型时，点完成应失败，提示要先量房。
- 提交后进度为「量房完成」。
- 李女士能看到户型摘要，但 **没有** 自己去画户型的入口。
- 小美、张总也不能从自己的页面进入量房编辑。
- 电脑网页 **不能** 量房，这是规定。

- [ ] 只有阿强能从任务进入量房
- [ ] 提交后客户能看到摘要，不能自己改图

### 3.6 小美发布效果图

小美点底部「设计」，为李女士出图。  
图画出来之后，必须再点 **发布**，李女士才能看见。电脑后台也可以发布或撤回。

应出现：

- 没发布的图，李女士看不到。
- 发布后，李女士服务档案里出现方案图。
- 进度变为「方案已发布」。
- 撤回后，李女士马上看不到那张图。

- [ ] 不发布则客户不可见
- [ ] 发布、撤回都立刻生效

### 3.7 签单和记账

小美或张总在这一单上确认签单。若提成按百分比计算，先填合同金额（必须大于 0）。

应出现：

- 电脑 **三方提成** 里出现 **3 条** 待支付：老周、小美、阿强。
- 老周手机「收益」能看到自己这一笔，仍看不到李女士手机号。
- 小美、阿强手机「收益」也能看到自己对应的那一笔。
- 张总可以改待支付金额或收款人（电脑后台），或在电脑/手机标记「已经线下打款」。
- 只要其中一笔已经点过已付，就不能整单撤销签单。
- 进度为「已签约」。

- [ ] 三条提成都在
- [ ] 老周能看到自己的收益
- [ ] 小美、阿强也能在「收益」看到自己的提成
- [ ] 张总能在手机「提成」看到同一批台账，并对待支付行点「已线下打款」
- [ ] 已付款后不能随便撤销

## 第四部分：员工发码这一单（王先生，必测）

换 **王先生的微信**。小美或阿强出示的是 **个人活动码**，不是老周那种推广码。

1. 王先生扫码后的说明页 **可以出现公司名称**（这是公司自己获客，和介绍人那张码不同）。
2. 允许手机号后建档。
3. 谁出示码，谁就负责上门测量这一侧：小美出示则小美兼顾设计和测量；阿强出示则系统另外安排设计师。
4. 可以马上量房，也可以先约时间。
5. 后面量房、发布、签单，与第三部分相同。

应出现：

- 成功页仍然只给设计师个人微信，不展示「这是哪家公司的员工」。
- 想约的时间和阿强已有安排冲突时，**不会** 自动换成别人，应提示换个时间。
- 签单后提成只有 **2 条**（设计师、测量员）。同一个人兼顾两项，两行都是他。
- 小美、阿强手机「收益」能看到自己对应的那一笔。
- 老周的进度和收益里 **没有** 王先生这一单。

- [ ] 活动码说明可以有公司名
- [ ] 冲突不会偷偷换测量员
- [ ] 只有两笔提成
- [ ] 介绍人看不到这一单

## 第五部分：客人没来，预约过期了（必测）

这一段专门测「约好了但过了时间还没上门」。请单独做一次，不要跳过。

### 5.1 怎么让它尽快过期

平时一次量房是 2 小时，干等太久。内测时张总可以到 **预约设置** 把「默认量房时长」临时改成 30 分钟，约最近一档，等到 **结束时间过了** 再看。

测完请改回 120 分钟，再点一次保存确认。

结束时间过后，屏幕应写「预约已过期」。  
如果还是不能点「重新预约」，张总到后台 **通知记录** 点一次 **执行提醒扫描**，然后大家刷新再试。

### 5.2 过期之后，每个人应怎样

| 谁 | 应看到 | 应能做 | 不应再怎样 |
| --- | --- | --- | --- |
| 李女士「服务」 | 预约已过期 | 重新选一个上门时间 | 界面还假装能改旧时间 |
| 小美工作台 | 有待处理 | 帮她约新的一档 | 还当成正在进行的预约 |
| 阿强工作台 | 过期的不在「已确认」里 | 在待处理或历史里找得到 | 过期的还占着今天已确认 |
| 张总「经营」 | 过期还没重新约，算异常 | 帮忙协调 | 混在普通列表里看不出来 |
| 老周「进度」 | 能看出过期或待重约 | 只能看，不能改 | 看到手机号或门牌 |
| 张总电脑线索转化 | 能筛出已过期 / 待重约 | 重新预约 | 只写「量房中」看不出过期 |

重新预约是 **约新的一趟**，不是去改已经过期的那一张。约成功后，进度回到「已预约上门量房」。

如果房子其实已经量完：即使预约过期，也应优先显示「量房完成」，还可以补点「完成」；如果还没量，就只给重新预约，不要自动当完成。

小美或张总取消预约（必须填原因）后，进度为「待重新预约」，李女士或小美应能再选新时间，阿强旧档期应空出来。

- [ ] 过期后客户看到过期，并能重新约
- [ ] 阿强已确认列表里没有过期单
- [ ] 张总能在经营里看到这件事
- [ ] 老周仍看不到隐私信息

## 第六部分：故意试这些不该成功的事

下面每条都是在确认系统会拦住。拦不住才是问题。

1. 李女士把预约页面转发给另一个微信 → 对方不能改时间、不能看详细地址。
2. 老周看进度和收益 → 没有客户手机号、没有精确门牌、没有户型图、没有内部改期原因、没有设计文件。
3. 用客户或介绍人身份，去打开量房页面（别人把链接发过来也算）→ 应提示没权限并回到自己的首页，不能闪一下编辑器。
4. 阿强身份下去找「设计」发布效果图 → 不应有这个入口，硬进也要被拒绝。
5. 张总身份下直接量房或自由出图 → 没有这些工具，需要先切换成小美或阿强。
6. 老周已经加入 3 家公司，再加第 4 家 → 应明确说到上限（默认 3 家）。
7. 小美已经是这家员工，再扫另一家的员工入驻码 → 不能偷偷换成另一家。
8. 老周退出这家公司后，再用旧推广码给新客户扫 → 应失败；以前已经介绍成功的单子还在。
9. 李女士服务还没结束时，再扫另一张推广码 → 应回到她已有的服务，不能暴露新公司，也不能再开一单。
10. 把小程序滑掉再打开、重新登录、切换身份 → 应进入现在这个身份该进的首页；身份失效时要说清楚，不能悄悄变成普通客户。
11. 底下小红点如果暂时读不到 → 应写「暂时无法读取」，不要显示 0。

- [ ] 转发看不了别人的预约
- [ ] 介绍人看不到隐私
- [ ] 各自身份进不了不该进的功能
- [ ] 一户进行中的服务不会被另一张码抢走

## 第七部分：这些不是毛病，请不要当故障报

产品就是这样设计的：

1. 介绍人给客户看的领取页 **没有公司名** —— 避免暴露介绍人和哪家公司合作。
2. 客户不能自己取消预约 —— 取消由设计师或老板来做。
3. 电脑网页不能量房 —— 量房只在测量员手机里做。
4. 有时上面仍写着「量房中」，但旁边进度是「预约已过期」—— 请看进度这几个字。
5. 员工活动码介绍来的客户，没有介绍人提成，老周也看不到。
6. 老板身份不能直接当设计师、测量员用，要切换。
7. 系统不帮公司给员工转钱，只记账。张总线下打款后，可在电脑或手机「提成」点已付。
8. 设计师没点「发布」的效果图，客户看不见。
9. 测试版小程序的码，扫不进正式版小程序。换环境要重新生成码，旧图不会自己变。
10. 页面已经约上了或已经过期了，但微信没有弹出服务通知 —— 先看当时有没有允许订阅。页面状态对了，通常仍算功能正常。

## 卡住了怎么办

1. 小程序先下拉刷新，或关掉再打开。
2. 确认自己现在是对的身份（看「我的」）。不对就切换，不要硬点别人的菜单。
3. 扫不了码：确认扫的是哪一种（员工入职 / 介绍人入职 / 给客户的推广码 / 员工活动码），四种不能混。
4. 约不了时间：看是不是不在上班时间、是不是已经有人约了、是不是过期后还在点「改期」而不是「重新预约」。
5. 仍不行：按下面格式发群，附整屏截图（小程序请把手机顶部微信按钮那一块也拍进去）。

## 发现问题怎么发到群里

复制填写：

```text
我现在扮演：客户 / 介绍人 / 设计师 / 测量员 / 老板 / 电脑后台
用的微信号或后台登录名：（不要发验证码）
我点了：1. …  2. …  3. …
手册里写应该：……
我实际看到：……
截图：整屏
大约时间：例如 8月21日 14:32
```

请组织者自行判断急不急：

- **马上要修**：领不了服务、排不到人又重试不了、约不上或过期后约不成、量房存没了、客户看到别人隐私、签了单却没有提成记录
- **尽快修**：进度文字和真实情况不符、过期还占着测量员今天的已确认、老板经营里看不到异常、切换身份进错首页
- **可以稍后**：错别字、间距、小红点偶尔不对、微信通知没收到但页面是对的
