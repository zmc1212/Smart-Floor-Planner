# 小K 十阶段知识包（I7.1）

## 1. 定位

第一版每个阶段至少一组基础知识包。知识包用于回答业主、施工人员、设计师和老板的日常问题，不作为工程验收、规范裁定或企业规定本身。

实现：`admin/src/lib/xiaok-v1/stage-knowledge.ts`。

## 2. 每包字段

- `packId`、`stageId`、`version`、`status`
- `intro`：阶段介绍
- `faqs`：常见问题与回答，可限定受众
- `ownerConcerns`：业主关注
- `workerConcerns`：施工人员关注
- `commonGaps`：常见资料缺项
- `nextStage`：与下一阶段衔接
- `boundaries`：回答边界
- `publicReferences`：已核验公开资料；未核验不填
- `enterpriseCitationPolicy`：企业资料可用时优先引用

## 3. 当前十包

## 4. 引用与边界

- 企业资料由原 KnowledgeRetriever 提供；未配置时答案明确“本次未核实企业施工标准”。
- 公开资料只列已核对对象；例如水电阶段仅标注 `GB55020-2021` 给排水章节，强电/弱电条文是否现行另行核实。
- 知识包不写具体尺寸、材料参数、闭水时长、线径、管径或验收数值。
- 模型只能基于知识包和已核实来源表达，不得把通用常识写成企业规定。
- 答案守卫拦截无来源数字参数、完成/验收断言和未核实企业要求。

## 5. 版本管理

- 包 ID 带版本号，当前全部为 `v1`。
- 修改知识内容必须提升版本，并保持已发布 Agent 的 `knowledgePackId` 可追溯。
- 注册表加载时校验每阶段一个 active 包；缺失或重复即失败关闭。
- 后续企业自定义知识包可增加版本，但不得绕过现有企业、项目和受众权限。

## 6. 测试

`stage-registry.test.ts` 校验十包齐全、版本和状态；`stage-answer.test.ts` 校验问答匹配、企业边界、无据参数拦截和专业转交。
