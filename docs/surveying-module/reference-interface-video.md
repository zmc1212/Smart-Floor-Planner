## 已确认界面分区

| 区域 | 视频中可见控件 |
| --- | --- |
| 顶部 | 返回、2D 户型、3D、漫游、楼层、助手/帮助、保存。 |
| 画布 | 网格、指南针、长度/角度浮标、墙体、红线、光标、当前测量提示。 |
| 右侧测墙栏 | 直线、斜线、墙厚、输入模式、重置。 |
| 右侧保留功能栏 | 设置、参照、锁定层、面积、CAD、更多。 |
| 墙体上下文操作 | 测量侧/内外墙方向切换。 |
| 底部 | 操作模式入口、蓝牙入口、重置光标、新增/素材入口。 |
| 右下侧 | 撤销、重做及计数反馈。 |

## 可确认的测绘行为

1. 用户在画布上通过光标确定当前墙的起点、接续点或方向，而非通过方向选择弹窗推进。
2. 红色墙线被明确提示为测量位置，墙体厚度以灰色实体显示在红线一侧。
3. 数字输入以毫米为单位，确认后当前墙段立即落图，光标进入新端点。
4. 直线和斜线是同级测量模式；斜线模式可以在画布流程中使用。
5. 已存在墙体的红线末端可作为继续绘制的锚点。
6. 画布平移、缩放、重置光标及撤销重做与测量过程共存。

## 推断而非已确认的事项

以下内容在实施前仍需通过更多录屏、真机操作或产品决策确认：

- 蓝牙读数触发后，系统是否自动确认墙段，还是还需点击确认。
- 斜墙角度是否可直接输入、由手势决定，或依赖额外测量方式校准。
- 闭合时的吸附距离、墙侧误差修正方式和复杂房型空间识别算法。
- 墙厚是户型默认值、每墙可覆盖值，还是二者兼有。
- CAD、面积、锁定层和参照的完整参数及数据格式。

## 资料缺口

- 门、窗、柱体、梁体、设备、楼梯等构件的放置与测量录屏。
- 多房间共享墙、内墙转角、异形闭合和已有户型复测的完整流程。
- 蓝牙设备交互中的失败、超时、断连和重新测量反馈画面。

资料缺口对应能力在 [后续功能库存](./future-parity-backlog.md) 中保持 `Deferred`，不应凭猜测合入第一原型。
