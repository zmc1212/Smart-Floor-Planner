# 正式量房模块

`miniprogram/pages/surveying-editor/` 是唯一正式量房页面。它以共享墙图为唯一数据源，支持墙体、空间、门窗、蓝牙读数、草稿恢复和正式提交。

## 数据与入口

- 所有入口传递 `leadId` 和/或 `floorPlanId`。
- `FloorPlan.layoutData` 使用 `version: 4`、`measurementMode: 'surveying'` 和 `surveyGraph`。
- 后台、CAD、报告、3D 和 AI 通过读适配层消费墙图，不保存旧布局镜像。

## 斜墙测角

- 斜线松手后保留为待确认预览；从预览终点继续拖拽会按实时预览长度落定当前墙，并以该终点开始下一条墙。点击顶部 `∠` 值或画布中当前拐角的角度标注，均可进入复用复尺数字面板的测角界面。画布仅保留最后一条斜墙与前一条墙的夹角；最后确认的斜墙未闭合且没有门窗时，也可点击该标注重开测角。
- 当前斜线与上一条斜线的正向相差不超过 8° 时，画布吸附到上一条斜线方向并显示辅助虚线；超过该阈值仍按自由角度绘制。
- `手机测量角度` 使用手机姿态传感器提供相对夹角，必须由量房人员确认；它是现场辅助能力，不替代高精度电子角度仪。
- `勾股定理测量角度` 依次测量两边和端点连线，按余弦定理计算夹角。三条蓝牙读数均写入正式测量审计，确认角度后仍需按常规流程确认墙长。

## 运维
