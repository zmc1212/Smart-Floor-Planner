## 第一原型明确不实现

| 功能 | 处理方式 |
| --- | --- |
| 正式户型保存和云端同步 | 当前只允许按线索隔离的新版本地体验草稿，以及可关联线索并在后台只读查看的 `surveying_prototype` 服务端草稿；Phase 5 再接正式兼容数据。 |
| 测量审计日志 | 与正式保存一并设计，避免记录原型假数据。 |
| 报告、CAD 和导出 | 仅保留禁用入口，待兼容适配器完成。 |
| 3D、漫游和多楼层 | 仅保留顶部布局位置，不生成伪预览。 |
| 旧版门窗测量 | 不挂接到新版墙图，以免形成双重几何真相。 |

## 门窗与构件资料状态

本地操作录屏已经提供门窗/构件的局部证据：可选中墙上对象、显示红色定位线、输入长度/宽度/高度/距地/边距、进入 3D 构件编辑和材质分类。资料状态应理解为“局部已观察，完整流程待确认”，相关实现不能只凭局部画面直接编码。以下能力在完成交互合同前保持 `Deferred`，不得混入 Phase 1-3 墙体原型：

| 功能组 | 需要补充观察的决策 |
| --- | --- |
| 门窗放置 | 已观察到已有对象编辑；仍需确认如何选择墙、是否先放置再测距、与红线/墙侧的关系。 |
| 洞口测量 | 已观察到尺寸和边距输入；仍需确认偏距含义、测量端选择、蓝牙读数提交顺序。 |
| 修改与复尺 | 已观察到选中、编辑、删除入口；仍需确认移动、重测、开向切换、撤销重做行为。 |
| 构件素材 | 已观察到 3D 构件材质分类；仍需确认柱、梁、电器、水路、楼梯等对象入口与尺寸机制。 |
| 输出兼容 | 仍需定义门窗和构件如何进入 CAD、报告、3D 展示和正式保存。 |

## 新资料录入流程

1. 将新增视频、截图或官方说明链接记录到 [参考视频分析](./reference-interface-video.md) 或新增同目录参考文档。
2. 将能够确认的交互变更更新到对应架构文档。
3. 在 [路线图与验收](./roadmap-and-acceptance.md) 调整阶段状态、依赖和验收场景。
4. 仅在实现行为实际进入源码后，更新根目录双语 `AGENTS` 的已实现/受影响模块说明。
