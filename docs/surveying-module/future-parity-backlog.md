## 第一原型明确不实现

| 功能 | 处理方式 |
| --- | --- |
| 正式户型保存和云端同步 | 只允许新版专用本地体验草稿，Phase 5 再接正式数据。 |
| 测量审计日志 | 与正式保存一并设计，避免记录原型假数据。 |
| 报告、CAD 和导出 | 仅保留禁用入口，待兼容适配器完成。 |
| 3D、漫游和多楼层 | 仅保留顶部布局位置，不生成伪预览。 |
| 旧版门窗测量 | 不挂接到新版墙图，以免形成双重几何真相。 |

## 门窗与构件待补资料

用户已明确门窗将在后续版本依据补充参考图和联网资料彻底重构。以下能力在获取资料前保持 `Deferred`：

| 功能组 | 需要补充观察的决策 |
| --- | --- |
| 门窗放置 | 如何选择墙、是否先放置再测距、与红线/墙侧的关系。 |
| 洞口测量 | 偏距、宽度、高度、测量端选择、蓝牙读数提交顺序。 |
| 修改与复尺 | 已放置门窗如何选中、移动、重测和切换开向。 |
| 构件素材 | 柱、梁、电器、水路、楼梯等对象的画布入口与尺寸机制。 |
| 输出兼容 | 门窗和构件如何进入 CAD、报告与 3D 展示。 |

## 仍需研究的墙体细节

| 问题 | 影响阶段 | 默认处理 |
| --- | --- | --- |
| 斜墙是否需要三边精密校角 | Phase 2/4 | 原型按拖拽角度 + 长度确认，现场验证后再增加校准。 |
| 自动闭合容差和误差校正提示 | Phase 2/4 | 第一原型默认 `200 mm`，不自动修正超差墙链。 |
| 墙厚是否支持逐墙覆盖 | Phase 2 | 支持当前墙覆盖并继承最近值。 |
| 参照层和锁层的数据语义 | Phase 6 | 在正式数据阶段后定义，原型不保存。 |
| 多层复制是否复制墙图或仅作参照 | Phase 7 | 待产品操作样例确认。 |

## 新资料录入流程

1. 将新增视频、截图或官方说明链接记录到 [参考视频分析](./reference-interface-video.md) 或新增同目录参考文档。
2. 将能够确认的交互变更更新到对应架构文档。
3. 在 [路线图与验收](./roadmap-and-acceptance.md) 调整阶段状态、依赖和验收场景。
4. 仅在实现行为实际进入源码后，更新根目录双语 `AGENTS` 的已实现/受影响模块说明。
