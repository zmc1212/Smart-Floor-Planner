# 界面外壳架构

> 状态：`Planned`  
> 目标：用独立页面承载知户型式工作台布局和交互节奏，同时保持本产品品牌表现。

## 页面与组件边界

新版代码实现时采用以下边界，避免继续扩张旧编辑页：

| 位置 | 职责 |
| --- | --- |
| `miniprogram/pages/surveying-editor/surveying-editor.*` | 页面编排、会话状态、页面级工具动作和原型草稿生命周期。 |
| `miniprogram/components/surveying/survey-canvas/` | 网格、墙体、红线、光标、尺寸、命中检测、平移与缩放。 |
| `miniprogram/components/surveying/survey-topbar/` | 返回、模式占位、楼层、帮助和保存/原型状态入口。 |
| `miniprogram/components/surveying/survey-side-tools/` | 直线、斜线、墙厚、输入模式、重置及后续保留功能分组。 |
| `miniprogram/components/surveying/survey-bottom-controls/` | 操作模式、蓝牙/手输入口、重置光标和新增功能入口。 |
| `miniprogram/components/surveying/survey-number-pad/` | 毫米数字输入、确认和关闭。 |
| `miniprogram/utils/surveyWallGraph.js` | 墙图领域操作，不直接依赖页面渲染状态。 |
| `miniprogram/utils/surveyLegacyAdapter.js` | 正式接入阶段才启用的旧数据兼容转换层。 |

第一原型可以将轻量视图组件暂存于页面目录，但墙图计算和蓝牙输入归属不得混进渲染逻辑。

## 控件职责与阶段

| 区域 | 第一原型可操作 | 后续对标 |
| --- | --- | --- |
| 顶部栏 | 返回；`2D` 激活；其余以禁用/敬请期待呈现。 | 3D、漫游、楼层、帮助、正式保存。 |
| 测墙工具栏 | 直线、斜线、墙厚、输入模式、重置光标。 | 快捷工具定制、其他墙编辑动作。 |
| 保留功能栏 | 可见但禁用，清楚标注未开放。 | 设置、参照、锁定层、面积、CAD、更多。 |
| 底部栏 | 蓝牙入口、手输入口、光标复位。 | 构件素材、新增类型和自定义模式。 |
| 画布 | 光标、墙段、红线、尺寸/角度、闭合提示、选墙复尺、导航手势。 | 多空间、楼层叠加、参照与构件。 |

## 画布显示规则

- 背景始终显示等距网格；单位换算由视口层处理，领域数据仍为整数毫米。
- 当前待确认墙使用高亮红色测量线和半透明墙体；确认墙使用稳定实体色，选中复尺墙重新高亮。
- 红线必须保持可辨识，不能因墙厚、缩放或选中颜色而被遮盖。
- 当前墙附近显示长度标签；斜墙同时显示夹角；闭合候选时显示明确的闭合动作入口。
- 光标由十字定位符和可选辅助虚线组成；未处于测墙会话时可以被重置到视口中心。
- 禁用功能仍可展示布局位置，但点击只提示阶段状态，不产生伪数据。

## 触控与层级

| 手势/动作 | 行为 |
| --- | --- |
| 点击空白画布 | `idle` 时放置光标；测量中不误清空待确认墙。 |
| 单指拖拽空白 | 平移画布。 |
| 双指缩放 | 围绕双指中心缩放，保持墙图毫米坐标不变。 |
| 从光标拖动 | 创建或修改当前墙预览；直线模式吸附正交，斜线模式保留任意方向。 |
| 点击墙体 | 选中墙并进入复尺/墙侧调整上下文。 |
| 点击墙端点 | 在支持阶段作为新墙锚点；第一原型仅处理当前闭环端点。 |

交互命中优先级固定为：浮动面板 > 工具控件 > 光标/墙端点 > 墙段 > 画布导航。

## 品牌与对标原则

- 保留参考产品的布局信息密度、常驻工具位置和“画布不中断”的操作方式。
- 图标、配色、提示语、帮助入口和资产必须采用本产品设计语言。
- 不复用参考产品 logo、机器人形象、营销角标或教程素材。
- 所有后续视觉稿必须以真实手持现场场景为验收对象，保证测量数字、光标和红线在亮屏环境下清晰可读。

## 旧版并行入口

进入实现阶段后，业务入口应提供明确区分：

- `旧版测量`：继续进入当前 `editor`，不改变已有草稿行为。
- `新版测绘体验`：进入 `surveying-editor`，第一原型展示“体验版，不会同步正式户型”的提示。

默认入口的替换条件由 [路线图与验收](./roadmap-and-acceptance.md) 约束。
