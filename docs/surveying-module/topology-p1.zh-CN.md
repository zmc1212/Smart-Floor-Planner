# 拓扑 P1 当前实现与验证

状态：**Implemented**。对应[优化计划](./topology-algorithm-optimization-plan.zh-CN.md)的七项 P1 缺陷；不代表 P2 或四个阶段的全部扩展已完成。

## 当前运行合同

1. 自动保存指纹递归覆盖持久化业务字段，包括门窗 `centerOffsetMm`、尺寸/模型/材质、墙体原始读数与平差、测量面修正、房间名称/有序边界/墙面覆盖、楼层属性和设置；对象键排序，排除视口、普通 session、顶层保存状态及时间戳。P0 的 `pendingMeasuredClosure` 单独纳入。移动门窗会触发自动保存和本地/云端新旧比较。
2. 房间内外侧按有向边界绕向及当前边的局部法向确定，墙体显式 `bodyNormalSide` 和房间显式 `wallFaceOverrides` 仍有效。C 形凹房间不再依赖可能位于房间外的全局质心。full validator 直接检查净边界的简单性、绕向、最小面积（10,000mm²）及各边前进方向；即使双轴反转后有符号面积仍为正，也拒绝 `INVALID_SPACE_INNER_BOUNDARY`。
3. 闭合与复尺共用 `domain/wall.js` 的预算函数：墙长 2%，夹在 25–150mm；残差上限 1,000mm。闭合维持既有坐标修正预算，复尺同时检查相对原始读数的累计修正，禁止连续复尺逐次绕过预算；full 校验拒绝超限 `remeasure-balance` 审计及其累计值。6m→20m 原子拒绝并要求补测。既有吸附、墙面 inset/extension 和 `coordinate-rounding` 审计不是本轮复尺平差，仍保留其原有语义；不将这些审计粗暴套用为闭合噪声。共享墙、共享节点联动及斜闭环复尺仍不支持。
4. 同宿主墙门窗按区间排序，重叠或端点相接返回 `OPENING_OCCUPANCY_CONFLICT`，含宿主墙及两门窗 ID；严格正间距允许。宿主墙自身端点仍允许贴边，已有拆墙 50mm 保护距离不变。增改门窗、落墙、拆墙、保存和恢复都经过统一校验；失败保留原图和历史。
5. 完成写入必须至少有一个闭合房间，所有 Space 闭合，所有普通墙参与有界 Face；其他开链返回 `INCOMPLETE_WALL_CHAIN`。草稿仍可保存合法开链并保留 `DANGLE_WALL` 警告。**Limited**：独立墙/半墙标记与交互尚未实现，因此没有绕过完成条件的用途豁免。
6. 事务在克隆及执行几何前做结构预检；保存/恢复和服务端写入同样先检查集合元素、ID、引用类型、整数毫米和会话点结构。`null` 元素、`null`/字符串坐标、小数墙长等返回稳定 `code/path/details`，不进入几何运算或数据库。空间会话引用也检查存在性。无效本地草稿继续由 P0 恢复记录保留原文及诊断，空图不能覆盖。
7. 未改变的完整边界优先保留原身份；真实分割由最大面积子房间继承 ID/名称，合并由最大原房间继承；平手按规范化边界坐标比较，不按墙数组顺序。删除前在事务局部捕获旧面积/边界，不持久化派生身份缓存。保持已有房间输出顺序，避免共享墙的隐式实体侧仅因求面枚举而翻转。

## 入口、权限与兼容边界

唯一运行入口仍为 `packages/surveying/editor/surveying-editor`；`POST /api/floorplans`、`PUT /api/floorplans/[id]` 使用同一生成镜像校验，错误保持 422 `validation.mode/errors/stats`，非法外壳仍为 400。路由、角色、租户边界和 `layoutData = { version: 4, measurementMode: 'surveying', surveyGraph }` 不变。Admin、Canvas、DXF、3D 和 AI 继续只读消费墙图。没有历史数据自动修复或迁移；历史异常数据会被拒绝，应保留原始数据后补测处理。

视觉来源沿用双语还原台账中 `surveying-editor` 的当前行。仅修正几何和已有错误反馈数据路径；WXML、样式、图标、图片及导航均未修改。未控制微信 DevTools；390×844 与长屏真机截图核验仍待用户提供，不能视作已通过。

## 验证

新增 `survey-topology-p1.test.js` 的 40 项回归包含独立面积预期、旋转/镜像/平移、数组重排、分割/合并身份、累计复尺、门窗相接、异常元素、原子失败和保存重载/撤销重做快照；编辑器增加两项本地恢复/完成写入检查；Admin 增加三项写入反例矩阵。

旧 500mm 复尺成功样例改为预算内 50mm，超预算行为由独立 P1 拒绝测试覆盖。Phase 3 冻结参考仅显式修订已知错误的质心公式，使用独立鞋带绕向计算；Phase 4B 冻结删除仅补齐删除前身份捕获及结构预检，其他冻结算法保留。行为快照的凹角外皮及房间身份变化已经过 diff 审查，不以重写快照代替 P1 几何断言。

512 墙/240 房间独立 Node 基准：full 校验中位数约 35ms、P95 约 39ms，通过既有 62ms 门槛；不是低端真机性能承诺。最终测试结果见交付检查表。

P2 的 `revision/baseRevision` 条件更新、完整 snap rounding 和低端真机预算仍待实施。
