# 路线图与验收

> 状态：`Planned`  
> 交付原则：先验证最影响现场效率的墙体测量闭环，再接数据、完整工作台和下游能力。

## 难度分组

| 难度 | 能力 | 原因 |
| --- | --- | --- |
| Low | 文档基线、独立页面外壳、静态保留功能入口 | 不涉及复杂几何或正式数据。 |
| Medium | 单空间光标绘墙、直/斜墙、墙侧/墙厚、手输、BLE 输入与异常保护 | 状态明确，可在隔离原型中验证。 |
| Medium-High | 设置/参照/锁层/面积/CAD 菜单、备份恢复 | 依赖稳定墙图和产品参数定义。 |
| High | 多空间共享墙、正式持久化适配、下游导出、楼层与 3D/漫游 | 涉及拓扑、兼容数据和跨模块消费。 |
| Deferred | 门窗和完整构件素材 | 缺少目标流程参考资料，暂不设计。 |

## 依赖顺序与阶段状态

阶段顺序按“低风险验证 -> 输入闭环 -> 数据接入 -> 完整对标”排列；后期阶段即便单点难度较低，也不能早于其数据依赖交付。

| Phase | 难度 | 状态 | 交付内容 | 退出条件 |
| --- | --- | --- | --- | --- |
| 0. 文档与参考基线 | Low | `Validated` | 本目录主文档、视频证据、架构合同和验收表。 | 所有文档链接存在，范围和待确认边界清晰。 |
| 1. 独立页面外壳 | Low | `In Progress` | `surveying-editor` 页面、双入口、网格、顶部/右侧/底部布局、禁用保留功能、撤销重做容器。 | 不触碰旧编辑流程；真机可进入新版页并匹配工作台信息结构。 |
| 2. 手动墙体原型 | Medium | `In Progress` | 墙图内存模型、光标、直线/斜线、毫米手输、墙厚/墙侧、单空间闭合、复尺、历史。 | 完成全部手动原型验收场景。 |
| 3. BLE 测距原型 | Medium | `Not Started` | 设备入口、当前墙接收读数、命令超时、重复过滤、断线重连、本地原型恢复。 | 现场用指定测距仪完成一个闭合空间且无误提交。 |
| 4. 墙图编辑能力 | High | `Not Started` | 多空间、共享墙、端点捕捉、从已有墙接续、删除/修正与空间重算。 | 多房间样板图可连续重建且墙关系稳定。 |
| 5. 正式数据接入 | High | `Not Started` | schema、云端草稿、审计日志、旧 v2 适配器、报告/CAD/3D 消费桥接。 | 新版保存结果可被现有下游读取，旧草稿不回归。 |
| 6. 2D 保留功能对标 | Medium-High | `Not Started` | 设置、参照、锁定层、面积、CAD/导出、更多菜单、快捷栏和备份管理。 | 参考视频中的 2D 常驻功能均有可验收行为。 |
| 7. 楼层与展示模式 | High | `Not Started` | 多楼层复制/切换、户型朝向、2D/3D/漫游、鸟瞰与多层显示。 | 多楼层可保存、恢复并在展示模式一致呈现。 |
| 8. 门窗与构件扩展 | Deferred | `Deferred` | 待参考资料后规划门窗、柱梁、设备、楼梯和素材。 | 收到流程材料并通过单独设计评审。 |
| 9. 现场验收与切换 | High | `Not Started` | 并行试点、数据比对、培训说明和默认入口切换决策。 | 准确性、恢复、下游和用户体验验收均通过。 |

## 第一可体验版本定义

第一可体验版本由 Phase 1 至 Phase 3 构成，必须满足：

- 新版独立入口可见，并明确标记为体验版；旧版入口不改变。
- 界面区域与参考视频的测绘工作台同构，但使用本产品视觉资产。
- 一个用户可以从空白画布出发，使用手输或 BLE 完成单空间闭合和一面墙复尺。
- 体验数据只在新版本地原型范围内存续，不写入正式 floor plan。
- 门窗、CAD、3D、多楼层等未启用控件不能制造看似完成的输出。

## 原型验收用例

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 页面隔离 | 分别打开旧版与新版入口。 | 旧版行为不变；新版清楚提示体验状态。 |
| 空白起测 | 在空画布放置光标并拖出墙。 | 出现待确认墙、红线和当前测量目标。 |
| 直线手输 | 输入 `2950 mm` 确认第一墙。 | 生成精确长度的正交墙，光标落在新端点。 |
| 斜线手输 | 选择斜线、拖出方向并输入长度。 | 墙按预览角度生成，同时显示长度与夹角。 |
| 墙侧/墙厚 | 切换测量侧并修改墙厚。 | 红线端点与长度不变，墙体偏移与空间预览更新。 |
| 连续闭合 | 连续添加至少三面墙并靠近起点。 | 出现闭合提示，确认后只生成一个闭合空间。 |
| 墙体复尺 | 闭合后选中一墙，输入新值。 | 仅目标墙进入复尺更新，闭合冲突给出明确处理反馈。 |
| BLE 读数 | 对待确认墙触发一次测距。 | 一次有效读数只提交当前墙一次。 |
| BLE 无目标读数 | 无待测墙时设备返回读数。 | 显示提示，不创建墙也不修改现有几何。 |
| 设备异常 | 模拟超时、重复包与断连。 | 不生成重复墙；预览与已确认数据可恢复操作。 |
| 画布导航 | 绘墙过程中平移、缩放、撤销重做、重置光标。 | 几何和输入目标保持一致，无误删已确认墙。 |
| 原型退出恢复 | 保存本地体验草稿后退出重进。 | 只恢复新版专用草稿，不污染正式项目或旧版草稿。 |

## 正式接入验收

Phase 5 开始后，新增以下门槛：

| 验收面 | 标准 |
| --- | --- |
| schema 迁移 | 新墙图带版本字段，旧数据可读，任何升级都保留回退路径。 |
| 兼容输出 | 闭合空间转换为旧布局后，尺寸、墙侧推导轮廓和单位换算误差在定义容差内。 |
| 日志 | 手输与 BLE 读数来源区分明确，复尺不生成误归属记录。 |
| 导出/展示 | 报告、CAD 与 3D 使用同一适配结果，不出现不同尺寸版本。 |
| 回归 | 旧 `editor` 草稿、门窗及已有正式户型读取功能不受新版入口影响。 |

## 切换门槛

仅当以下事项全部标记为 `Validated`，才讨论把新版设为默认入口：

1. 真实现场至少覆盖规则房、斜墙房和多空间户型。
2. BLE 和手输两种路径的数据准确性可对照复核。
3. 草稿中断恢复和异常重试不造成不可修复的户型损坏。
4. 当前业务依赖的保存、报告、CAD、3D 或其替代流程已经接通。
5. 门窗若仍未重构，产品已明确用户在新版后的可用补录路径。
