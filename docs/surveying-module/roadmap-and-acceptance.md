# 路线图与验收

> 状态：`Planned`  
> 交付原则：先验证最影响现场效率的墙体测量闭环，再接数据、完整工作台和下游能力。

## 难度分组

| 难度 | 能力 | 原因 |
| --- | --- | --- |
| Low | 文档基线、独立页面外壳、静态保留功能入口 | 不涉及复杂几何或正式数据。 |
| Medium | 单空间光标绘墙、直/斜墙、墙侧/墙厚、手输、BLE 输入与异常保护 | 状态明确，可在隔离原型中验证。 |
| Medium-High | 设置/参照/锁层/面积/CAD 菜单、备份恢复 | 依赖稳定墙图和产品参数定义。 |
| High | 多空间共享墙、正式持久化适配、下游导出、楼层与 3D/漫游 | 涉及拓扑、兼容数据和跨模块消费。 |
| Medium-High | 门窗和本地构件编辑原型 | 先验证选墙新增、尺寸/边距输入、3D 构件预览和本地模型选择；真实素材库与正式输出仍后置。 |

## 依赖顺序与阶段状态

阶段顺序按“低风险验证 -> 输入闭环 -> 数据接入 -> 完整对标”排列；后期阶段即便单点难度较低，也不能早于其数据依赖交付。

| Phase | 难度 | 状态 | 交付内容 | 退出条件 |
| --- | --- | --- | --- | --- |
| 0. 文档与参考基线 | Low | `Validated` | 本目录主文档、视频证据、架构合同和验收表。 | 所有文档链接存在，范围和待确认边界清晰。 |
| 1. 独立页面外壳 | Low | `In Progress` | `surveying-editor` 页面、双入口、网格、顶部/右侧/底部布局、禁用保留功能、撤销重做容器。 | 不触碰旧编辑流程；真机可进入新版页并匹配工作台信息结构。 |
| 2. 手动墙体原型 | Medium | `In Progress` | 墙图内存模型、光标、直线/斜线、毫米手输、墙厚/墙侧、单空间闭合、复尺、历史。 | 完成全部手动原型验收场景。 |
| 3. BLE 测距原型 | Medium | `Not Started` | 设备入口、当前墙接收读数、命令超时、重复过滤、断线重连、原型草稿恢复。 | 现场用指定测距仪完成一个闭合空间且无误提交。 |
| 4. 墙图编辑能力 | High | `Not Started` | 多空间、共享墙、端点捕捉、从已有墙接续、删除/修正与空间重算。 | 多房间样板图可连续重建且墙关系稳定。 |
| 5. 正式数据接入 | High | `Not Started` | schema、云端草稿、审计日志、旧 v2 适配器、报告/CAD/3D 消费桥接。 | 新版保存结果可被现有下游读取，旧草稿不回归。 |
| 6. 2D 保留功能对标 | Medium-High | `Not Started` | 设置、参照、锁定层、面积、CAD/导出、更多菜单、快捷栏和备份管理。 | 参考视频中的 2D 常驻功能均有可验收行为。 |
| 7. 楼层与展示模式 | High | `Not Started` | 多楼层复制/切换、户型朝向、2D/3D/漫游、鸟瞰与多层显示。 | 多楼层可保存、恢复并在展示模式一致呈现。 |
| 8. 门窗与构件扩展 | Medium-High | `In Progress` | 在新版本地原型中实现选墙新增门/窗、独立 3D 构件编辑、长度/宽度/高度/距地/边距输入、翻转、入户门标记和本地模型选择。 | 门窗属性与 2D 墙图同步并随 `surveying_prototype_draft_v1_{leadId}` 恢复；不接真实素材库，不写正式 floor plan、报告、CAD 或旧版 3D 下游。 |
| 9. 现场验收与切换 | High | `Not Started` | 并行试点、数据比对、培训说明和默认入口切换决策。 | 准确性、恢复、下游和用户体验验收均通过。 |

## 第一可体验版本定义

第一可体验版本由 Phase 1 至 Phase 3 构成，必须满足：

- 新版独立入口可见，并明确标记为体验版；旧版入口不改变。
- 界面区域与参考视频的测绘工作台同构，但使用本产品视觉资产。
- 一个用户可以从空白画布出发，使用手输或 BLE 完成单空间闭合和一面墙复尺。
- 体验数据以新版原型草稿存续：本地按线索使用 `surveying_prototype_draft_v1_{leadId}`，手动保存时可写入并关联服务端 draft floorplan，但必须标记 `measurementMode: 'surveying_prototype'` 和 `prototypeOnly: true`，后台仅只读查看，不作为正式兼容户型输出。
- 门窗、CAD、3D、多楼层等未启用控件不能制造看似完成的输出。

## 原型验收用例

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 页面隔离 | 分别打开旧版与新版入口。 | 旧版行为不变；新版清楚提示体验状态。 |
| 空白起测 | 在空画布放置光标并拖出墙。 | 出现待确认墙、红线和当前测量目标。 |
| 直线手输 | 输入 `2950 mm` 确认第一墙。 | 生成精确长度的正交墙，光标落在新端点。 |
| 斜线手输 | 选择斜线、拖出方向并输入长度。 | 墙按预览角度生成，同时显示长度与夹角。 |
| 墙侧/墙厚 | 切换测量侧并修改墙厚。 | 红线端点与长度不变，墙体偏移与空间预览更新。 |
| 连续闭合 | 连续添加至少三面墙并靠近起点。 | 出现闭合提示，确认后只生成一个闭合空间。 |
| 墙体复尺 | 闭合后选中一墙，输入新值。 | 仅目标墙进入复尺更新，闭合冲突给出明确处理反馈。 |
| BLE 读数 | 对待确认墙触发一次测距。 | 一次有效读数只提交当前墙一次。 |
| BLE 无目标读数 | 无待测墙时设备返回读数。 | 显示提示，不创建墙也不修改现有几何。 |
| 设备异常 | 模拟超时、重复包与断连。 | 不生成重复墙；预览与已确认数据可恢复操作。 |
| 画布导航 | 绘墙过程中平移、缩放、撤销重做、重置光标。 | 几何和输入目标保持一致，无误删已确认墙。 |
| 原型退出恢复 | 保存本地体验草稿后退出重进。 | 只恢复新版专用草稿，不污染正式项目或旧版草稿。 |

## Phase 2 画布细节还原补强

本补强项用于把手动墙体原型从“可画墙”推进到“接近参考视频的测量体验”。验收重点不再只看墙段是否生成，而要确认画布上的测量线、墙体偏移、光标、尺寸标注和闭合反馈是否符合现场测绘语义。

当前实现进度：

- 已调整拖拽释放行为：有效预览墙释放后按预览长度快速成墙，`inputSource` 标为 `preview`，光标落在新端点以便继续拖第二面墙。
- 已补齐空白起测：无墙且处于空闲/已放置光标状态时，点击画布空白处会移动橙色光标作为起测点。
- 已明确手输入口：底部“手输 mm”和右侧“输入”保留为复尺和精确毫米修正入口。
- 已补强阶段反馈：底部模式、手输提示和闭合提示会随等待长度、复尺、可闭合、已闭合状态变化。
- 已接入新版专用本地体验草稿键 `surveying_prototype_draft_v1_{leadId}`，顶部“保存草稿”复用旧版保存草稿的显式操作反馈，额外写入 `surveying_last_draft_backup` 作为本地备份，并同步保存、关联带 `surveying_prototype` 标记的服务端草稿；后台可只读查看，仍不进入正式 CAD/报告/3D 兼容输出。
- 仍未启动 BLE 测距、正式保存、测量日志、导出和 3D；这些能力继续保持禁用或隔离。

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 拖动预览线 | 按住橙色光标拖出第一墙方向。 | 拖动中只出现橙色方向线和光标，不提前显示灰色墙体。 |
| 释放成墙 | 释放有效预览墙。 | 立即按预览长度提交墙体，显示灰色墙体、黑色轮廓、红色测量线和长度提示，不自动弹出数字键盘。 |
| 连续两墙 | 横向释放第一墙后，从新端点纵向拖出第二墙。 | 第二墙以第一墙末端为起点生成，形成 L 型墙链。 |
| 第三边矩形吸附 | 完成两面墙后，在直线模式拖出第三面墙并靠近第一墙起点对齐轴。 | 第三墙端点自动吸附到第一墙起点对齐轴，显示蓝色虚线辅助线；斜线模式不触发该吸附。 |
| 红线基准 | 切换墙侧或墙厚。 | 红色测量线端点和长度不变，灰色墙体只按墙侧偏移。 |
| 光标轴线 | 确认墙长后继续测下一墙。 | 光标吸附在墙角端点，蓝色虚线十字穿过该端点；拖动下一墙时蓝线保持在上一确认锚点。 |
| 尺寸标注 | 完成一段水平墙和一段竖向墙。 | 显示黑色尺寸辅助线、箭头和蓝色数值标签；竖向标签旋转显示。 |
| 顶部测量浮层 | 绘制第二段墙。 | 顶部深色浮层显示当前长度，并在可计算时显示夹角。 |
| 闭合反馈 | 端点接近起点。 | 显示橙色闭合辅助虚线和“合”按钮，确认后才闭合空间。 |
| 新房间墙体吸附 | 第一个房间闭合后点击“新建房间”，再点击已有墙体或墙角附近。 | 靠近墙角时光标落到两墙中线交点；点击墙段中部时落到墙中线投影点；点击重置光标可回到最近一次墙体吸附点。 |
| 共享墙闭合 | 第二个房间沿第一个房间外侧绘制，最后一墙靠回同一共享墙。 | 显示橙色闭合虚线和“合”按钮；确认后共享墙被切分，新旧空间引用正确墙段。 |
| 空白触摸 | 在画布空白处单指拖动。 | 不移动光标、不移动墙体、不创建预览；只有拖动光标才开始测墙。 |
| 空白点选起点 | 在无墙状态点击画布空白位置。 | 橙色光标移动到点击处，可从该点拖出第一面墙。 |
| 服务端体验草稿 | 点击顶部“保存草稿”后退出并重进新版页面。 | 本地恢复当前线索的新版专用草稿，同时服务端生成或更新并关联带 `surveying_prototype` 标记的 draft floorplan；后台线索和户型详情可只读查看墙图；未完成的预览墙不会以脏状态恢复；不覆盖旧版草稿或进入正式输出。 |
| 选墙新增门窗原型 | 点击已确认墙体后，使用墙上浮动工具新增门或窗。 | 门窗挂靠当前墙体中点，画布出现门/窗符号，选中后可编辑宽、高、距地，并随本地体验草稿保存恢复。 |
| 门窗原型删除边界 | 选中门或窗后点击右侧对象工具“删除”。 | 仅删除选中的本地原型门窗；墙体删除、打断、排布、3D 材质和正式门窗输出仍提示后续开放。 |

## 正式接入验收

Phase 5 开始后，新增以下门槛：

| 验收面 | 标准 |
| --- | --- |
| schema 迁移 | 新墙图带版本字段，旧数据可读，任何升级都保留回退路径。 |
| 兼容输出 | 闭合空间转换为旧布局后，尺寸、墙侧推导轮廓和单位换算误差在定义容差内。 |
| 日志 | 手输与 BLE 读数来源区分明确，复尺不生成误归属记录。 |
| 导出/展示 | 报告、CAD 与 3D 使用同一适配结果，不出现不同尺寸版本。 |
| 回归 | 旧 `editor` 草稿、门窗及已有正式户型读取功能不受新版入口影响。 |

## Phase 8 门窗与构件验收准备

Phase 8 不得直接从旧版门窗弹层或零散画面开始编码。启动实现前，必须先完成文档化交互合同，并把 [本地操作视频分析](./reference-local-operation-video.md) 中的局部证据转成可验收需求。

当前 `frame_074.jpg` 对应的选墙新增门/窗能力只作为本地原型提前验证交互，不改变 Phase 8 正式状态。后续仍需单独定义门窗测量、边距参考、2D/3D 同步和下游输出合同。

| 验收面 | 标准 |
| --- | --- |
| 需求准备 | 明确门窗/构件入口、选墙方式、对象类型、可编辑参数、撤销历史和禁用边界。 |
| 2D 构件编辑 | 选中对象后能显示墙上红色定位线、端点/控制点、对象浮层和右侧对象工具。 |
| 尺寸/边距输入 | 长度、宽度、高度、距地、边距1、边距2的单位、参考边和校验规则被写入需求合同。 |
| 3D 构件/材质 | 3D 预览、材质分类选择和 2D 对象属性同步关系明确，不生成第二套构件状态。 |
| 输出边界 | 在正式适配完成前，门窗/构件不得写入正式 floor plan、报告、CAD 或 3D 下游。 |


## Phase 8 门窗与构件本地原型补充

Phase 8 第一轮只实现新版 `surveying-editor` 的本地原型合同。门窗仍挂靠新版墙图 `floor.openings`，通过程序化 3D 模型和本地缩略图验证交互，不接真实远程素材库，也不改变旧版 `editor.*` 的正式测量能力。

当前实现范围：

- 新增门/窗后仍停留在 2D 平面图中显示并选中门窗；选中门窗后点击侧边对象工具“编辑”才进入整屏构件编辑场景，显示单面墙、地台、门窗模型、墙洞和红色尺寸线。
- 构件编辑整屏层顶部必须复用 `navigationSafeTop` 预留安全区，返回箭头在状态栏/胶囊按钮下方清晰可见，并只关闭 3D 构件编辑返回 2D。
- 3D 本地材质必须区分墙体、地台、门板、窗框和玻璃；红色尺寸线需要在墙体前后两面同时显示，并放到模型外侧避免被门窗主体遮挡。
- 3D 默认视角必须朝向门窗模型所在正面；切换长度、宽度、高度、距地、边距等规格 tab 时保留当前旋转/缩放状态，不自动跳到墙体背面。
- 规格页支持长度、宽度、高度、距地、边距1、边距2输入；边距根据墙长、中心偏移和构件长度换算。
- 点击任一规格 tab 必须直接打开大数字输入层；构件规格输入按键实时同步 3D 标注、门窗模型、2D opening 和本地草稿，确认按钮仅关闭输入层。
- 翻转页支持门内开/外开；窗暂固定窗位。
- 模型页提供本地分类和缩略图选择，仅写入 `modelId`、`modelCategory`、`materialId` 等原型字段。
- 门支持 `entryDoor` 标记，同一楼层只保留一个入户门。
- 输出边界保持不变：不写正式 floor plan、报告、CAD、测量日志或旧版 3D 下游。

## 切换门槛

仅当以下事项全部标记为 `Validated`，才讨论把新版设为默认入口：

1. 真实现场至少覆盖规则房、斜墙房和多空间户型。
2. BLE 和手输两种路径的数据准确性可对照复核。
3. 草稿中断恢复和异常重试不造成不可修复的户型损坏。
4. 当前业务依赖的保存、报告、CAD、3D 或其替代流程已经接通。
5. 门窗若仍未重构，产品已明确用户在新版后的可用补录路径。
