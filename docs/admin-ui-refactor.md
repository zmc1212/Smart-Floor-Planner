This file records the current Admin UI rules and the latest state of routes
that have an approved refactor direction. It is not a chronological migration
log. Git history contains earlier refactor attempts.

## Shared contract

- Next.js App Router pages use the established Ant Design 5 and Ant Design Pro
  system, including the shared `AdminAntdProvider` token configuration.
- Use `PageContainer`, `ProTable`, Ant Design form/feedback primitives, and
  established Admin business components where they fit the workflow. Do not
  introduce a parallel UI system for new Admin work.
- Page frames keep a 20px stack gap between sibling sections, wrap page-header
  extras instead of compressing titles, and keep table/filter/action labels on
  one line. Buttons that render as links (or sit inside `Link`) keep their
  intended text color so primary green and danger surfaces stay readable.
- Business pages preserve route, API, tenant, role, and mutation boundaries.
- Shared Admin controls belong in `admin/src/components/admin/*` or the
  established business-component area.
- Visible mutations use the shared success/failure operation feedback UI.
- Use `http://localhost:3006` for visual checks. Authenticated checks use the
  user's existing Chrome session.

## Handoff

`/login`, `/floorplans/kujiale`, the AI Studio cluster (`create` / `scenarios` / tool pages plus shared creation/workbench/ChatInterface helpers), `FloorPlanViewer`, and the Admin `Sidebar` shell now use Ant Design 5 controls. Dark studio shells keep their night theme via `ConfigProvider` + `studio-antd-theme`. Root layout mounts client `AntdReact19Patch` (`@ant-design/v5-patch-for-react-19`) so Ant Design 5 wave effects and static methods work on React 19. Root `AntdRegistry` enables css-in-js `layer` with `@layer theme, base, antd, components, utilities` so Tailwind utilities override Ant Design's global `a { color: colorLink }` (inactive sidebar items stay muted gray; only the active route uses primary green). Unlayered `a.ant-btn*` / `a .ant-btn*` color rules restore intended button contrast when those links still win. Shared `notify`, `ConfirmDialogProvider`/`useConfirmDialog` (antd `App.useApp().modal.confirm` under `AdminAntdProvider`'s `ConfigProvider` + `App`), `AccountSettingsProvider`/`useAccountSettings` (sidebar avatar account menu with login/sensitive-password modals), and `ImageUploadField` live under `admin/src/components/admin/*`. The former `@/components/ui` parallel kit and unused dead components (`UserDashboard`, `DepartmentTree`, `EnterprisePageHeader`, `enterprise-utils`) were removed.
