# Customer Service home chevron

The benefit-card `chevron-right` vector in this directory is adapted from
Lucide Icons v1.8.0, the same family already used by the login and
promotion-create Mini Program icons. It is rendered as a white transparent
PNG for the green `58rpx` benefit-card control.
