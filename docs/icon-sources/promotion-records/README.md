# Promotion records visual sources

The production hero scene at
`miniprogram/images/promotion-records/hero-scene.jpg` was generated with the
built-in OpenAI image generation tool from the user-supplied visual reference
`design-references/all-pages-ip-v1/09-promotion-records.png`. It contains no
third-party stock artwork and is used only as the page's decorative brand scene.

The page's search, record-category, and bottom-navigation raster icons reuse the
existing rounded Lucide-derived family under `miniprogram/images/mine-icons/`.
Its editable source and MIT attribution remain documented in
`docs/icon-sources/mine/README.md` and `docs/icon-sources/mine/LICENSE.md`. The
small create-action plus reuses the established Leads control crop documented in
`docs/icon-sources/leads/README.md`; chevrons remain simple CSS geometry.

Generation prompt summary: isolate Xiao K as an enterprise-filing assistant next
to the house-shaped partner-record cabinet, preserve the reference's soft matte
3D materials, green/white palette, viewing angle, and grounded warm-white scene,
and remove all surrounding interface text and controls. The production JPEG is
a width-optimized derivative of the generated PNG and remains below 40 KB.
