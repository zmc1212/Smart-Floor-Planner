# Code presenter V2 artwork

> Retained for backwards-compatible scan glyphs and existing surfaces. The two
> presenter routes now use the V3 pack documented in `../code-presenter-v3/`.

## Scope

`miniprogram/packages/business/assets/code-presenter-v2/` contains the route-specific artwork for:

- `packages/business/staff-activity-code/staff-activity-code`
- `packages/business/enterprise-join-codes/enterprise-join-codes`

## Provenance and licence

All files in this pack were generated as original, standalone transparent artwork with Codex built-in ImageGen on 2026-08-27 for this repository. They are project-owned production assets for the Smart Floor Planner Mini Program; no third-party icon pack, stock image, screenshot crop, embedded UI/text, or composite reference-frame slice is included.
