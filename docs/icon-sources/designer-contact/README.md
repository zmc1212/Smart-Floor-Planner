# Designer contact professional icon source

The professional-credential icons used by
`miniprogram/components/designer-contact-sheet` follow the same rounded Lucide
outline language as the Mini Program's other primary action icons.

Editable SVG sources live in this directory. Runtime PNG exports are stored in
`miniprogram/images/designer-contact/` and are rendered at `96x96` with
transparent backgrounds.

## Mapping

- `professional-badge.svg` -> `professional-badge.png`: Lucide `badge` with a
  compact star mark for the visible professional title.
- `professional-experience.svg` -> `professional-experience.png`: Lucide
  `compass` for career experience.
- `professional-service.svg` -> `professional-service.png`: Lucide
  `users-round` combined with a compact Lucide `heart` for customers served.

Source: [Lucide](https://lucide.dev/)
