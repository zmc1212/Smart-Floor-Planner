# AI studio timeline icon set

Runtime assets live in `miniprogram/images/ai-studio-icons-v3/` and are rendered
as transparent PNG files for reliable WeChat Mini Program display.

## Source mapping

- ByteDance IconPark `@icon-park/svg@1.4.2` outline icons: navigation, chevron,
  process/generate spark, message, picture, bookmark, edit, refresh, send, add,
  settings and check. IconPark is licensed under Apache-2.0; the bundled license
  is `ICONPARK-LICENSE`.
- Existing Lucide-derived project sources in `docs/icon-sources/ai-design/`:
  `floor-plan.svg` and `palette.svg`, recolored to the approved studio ink token.
  Their ISC notice remains in `docs/icon-sources/ai-design/LICENSE.md`.

The raster assets are generated by `tmp/generate-ai-studio-icons.js`; every
packaged PNG is transparent and below the project `300KB` asset limit.
