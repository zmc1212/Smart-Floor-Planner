# Customer project V4 icon source

The customer service archive uses one Lucide outline family to match the
approved V4 source at
`design-references/customer-project-archive-redesign-v4/customer-project-archive-balanced-color-v4.png`.

Editable SVG sources in this directory are rendered to transparent `96x96`
PNG files under
`miniprogram/packages/business/assets/customer-project-v4/`:

- `calendar-check.svg` -> `calendar-check.png`
- `designer-user.svg` -> `designer-user.png`
- `measurer-ruler.svg` -> `measurer-ruler.png`
- `dossier-file.svg` -> `dossier-file.png`
- `dossier-image.svg` -> `dossier-image.png`
- `dossier-delivery.svg` -> `dossier-delivery.png`
- `phone.svg` -> `phone.png`
- `message-circle-more.svg` -> `message-circle-more.png`

The calendar and delivery marks combine Lucide primitives to match the
approved floating-check treatment. Source: the `lucide-react` package already
bundled under `admin/node_modules/lucide-react`. License: ISC; the retained
license text is [`../promotion-create/LICENSE.md`](../promotion-create/LICENSE.md).
