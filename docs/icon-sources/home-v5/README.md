# Home v5 asset provenance

The former `miniprogram/images/home-v5/` rasters were derived from
the project-provided design reference:

- `design-references/home/miniprogram-home-vibrant-green-v5.png`

Those crops are no longer referenced by the Mini Program runtime and were
removed from the source package. The reference remains outside the Mini Program
package. Text, business data, status, and touch targets stay native WXML/Less.

These files did not introduce an external icon library or third-party stock
asset. Their usage and redistribution follow the ownership terms of the source
design supplied to this project.
