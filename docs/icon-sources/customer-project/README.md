# Customer project visual assets

The former `miniprogram/packages/business/assets/customer-project-v1/` Phase 6
rasters were generated with Codex's built-in image generator from the approved
customer-project design direction. They are no longer referenced by the runtime
and were removed from the source package. Current production uses the V4 icon
family under `packages/business/assets/customer-project-v4/` plus the
main-package Xiao K at `images/airy-v1/project-delivery-xiao-k.png`.

The source board is the project-owned ignored design reference
`design-references/referrer-network-appointment-v1/phase-6-customer-project-assets-board-v1.png`.
It had three equal cells:

- left: `project-delivery-xiao-k.png` — now the main-package Xiao K copy;
- middle: `formal-floor-plan-archive.png` — unused empty-state raster, removed;
- right: `published-design-folio.png` — unused empty-state raster, removed.

Formal-plan metadata and published-design images remain native UI bound to the
owner-only customer-project API.
