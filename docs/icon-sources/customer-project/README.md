# Customer project visual assets

`miniprogram/packages/business/assets/customer-project-v1/` contains three
page-specific Phase 6 assets generated with Codex's built-in image generator
from the approved customer-project design direction. No third-party stock art,
logo, or icon package is included. The two board-only empty-state assets are
retained as reviewed source files but excluded from the uploaded Mini Program
package because the current runtime renders those states with native UI; only
`published-design-folio.png` is a runtime asset today.

The source board is the project-owned ignored design reference
`design-references/referrer-network-appointment-v1/phase-6-customer-project-assets-board-v1.png`.
It has three equal cells and was deterministically cropped as follows:

- left: `project-delivery-xiao-k.png` — customer-project delivery-guide Xiao K;
- middle: `formal-floor-plan-archive.png` — formal v4 floor-plan archive state;
- right: `published-design-folio.png` — no-customer-visible-publication state.

All retained assets are transparent PNG files, individually optimized below the
Mini Program's 300KB generated-artwork limit. They are decorative or empty-state
art only; the formal-plan metadata and published-design images remain native UI
bound to the owner-only customer-project API.
