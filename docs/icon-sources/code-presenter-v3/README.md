# Code presenter V3 artwork

## Scope

`miniprogram/packages/business/assets/code-presenter-v3/` contains the latest
route-specific artwork for the staff activity-code and enterprise dual join-code
presenters.

## Provenance and licence

All files were generated as original, standalone transparent artwork with Codex
built-in ImageGen on 2026-08-27 for this repository. They are project-owned
production assets; no screenshot crop, embedded UI text, composite frame, or
third-party icon pack is included.

an alpha PNG below the `300KB` packaged-asset limit; no WebP is shipped.
