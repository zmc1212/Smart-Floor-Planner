## 3. Context and memory implementation constraints

1. **Layered assembly:** Budget separately for fixed rules/current request, relevant complete recent turns, current tasks/effective needs, rebuildable process summaries and retrieved history/live business evidence. Prioritize current requests, corrections/negation, unresolved issues and necessary conditions; preserve tool-call/result pairs. Do not derive authoritative business state from summaries.
2. **Compaction trigger:** Before each model call, estimate the complete request, including tool schemas, media estimates, reserved output and headroom for subsequent tool results. Pin `inputBudget`, `summaryTrigger`, `summaryTarget` and the estimation method per batch, with `summaryTarget < summaryTrigger < inputBudget`. At the trigger, first deduplicate/select retrieval, then summarize older complete turns to the target; never dispatch above the hard limit. Derive values from the authorized model and batch fixtures and record them in the phase-two contract. Retain conservative byte guards; do not copy another model's token limits.
3. **Summary integrity:** Store original message ranges/IDs, conversation revision, object scope, source versions/hashes and authorization dependencies; replace atomically only while sources/revisions remain valid. Rebuild from authorized originals instead of repeatedly summarizing only an older summary. Need memory and unresolved tasks must not survive solely as prose summaries. Summaries cannot create customer confirmation, approval or site facts; withdrawal also invalidates summaries/indexes.
4. **Recall and failure recovery:** Retrieve older originals for the current object and re-read sources; clarify minimally if ambiguity remains. Compaction failure preserves originals and the last valid state, degrading to bounded essential context. If current input or necessary evidence alone exceeds limits, use existing recoverable feedback rather than silently dropping conditions, inventing memory or retrying indefinitely. Effective facts remain rebuildable after archiving, without relaxing retention/audit rules.
