# 角色说明书 · 老板（张总）

先读完《所有人先看》，再读这一份。主要用：**电脑网页 + 手机**。

---

## 你负责什么

- 开张前把公司准备好（入职码、员工、预约规则、提成规则）
- 看「这一单」排没排上人、过期没重约等异常
- 签单后记账，线下打款后点「已线下打款」
- **不能**直接量房、不能直接出效果图；要做这些请切换成设计师/测量员身份

---

## 你在流程图里的位置

```text
开张准备 → 发入职码
     ↓
客户进来后：盯「待派单 / 过期未重约」
     ↓
签单 → 三方提成台账 → 已线下打款
```

朋友介绍：应看到 **3 笔**提成。员工活动码：应看到 **2 笔**提成。

---

## 开张前清单（电脑）

打开组织者给的后台地址 → 左侧 **推荐网络 → 运营工作台**。各项就绪后再让客户扫码。

1. **推荐网络 → 入驻码**  
   - 下载 **员工入驻码**（给小美、阿强）  
   - 下载 **介绍人入驻码**（给老周）  
   - 两张不能混用；换新码后旧码应立刻失效  

2. **员工管理**  
   - 小美：启用、未暂停自动派单、有微信号、有个人微信二维码  
   - 阿强：启用、未暂停自动派单（可不传二维码）  

3. **推荐网络 → 预约设置** → 点 **保存并确认预约规则**  
   常用：每天 9:00–18:00、每次 2 小时、半小时一格、最多 30 天、客户提前 2 小时改期  

4. **三方提成** → 介绍人、设计师、测量员三条都打开（测「朋友介绍」必须三条；只测活动码时至少设计师+测量员两条要启用）  

5. 运营工作台确认「小程序码能生成」正常  

打勾：

- [ ] 两张入驻码都能打开  
- [ ] 小美资料齐全且未暂停  
- [ ] 阿强未暂停  
- [ ] 预约规则已确认  
- [ ] 三条提成已启用  

---

## 测的时候你要盯的点

### 1）朋友介绍这一单

- [ ] 李女士授权前，后台还没有这一单；授权后才出现  
- [ ] **线索转化**里能看到进度：已匹配测量员 / 待派单等  
- [ ] 人员齐全时，已指定小美和阿强  

### 2）故意缺人（可选）

- [ ] 暂停自动派单后再来新客户 → 停在「待派单」  
- [ ] 手机「经营」能看到异常  
- [ ] 补人后点 **重试派单** → 能排上  

### 3）预约与过期

- [ ] 电脑上能看到与手机相同的预约时间  
- [ ] 过期后能筛「已过期 / 待重约」，能帮客户重新预约  
- [ ] 「经营」里能看到过期未重约  

临时把量房时长改成 30 分钟可更快等到过期；测完改回 120 并再保存。若仍无法重约，到 **通知记录** 点一次 **执行提醒扫描**。

### 4）签单与提成

- [ ] 朋友介绍签单后有 3 条待支付  
- [ ] 员工活动码签单后有 2 条待支付  
- [ ] 手机「提成」能看到台账，可点「已线下打款」  
- [ ] 已付款后不能随便整单撤销  

### 5）介绍人退出

- [ ] 停用老周后续扫码后，新客户扫旧码失败  
- [ ] 以前已成功的单子和提成还在  

---

## 卡住了怎么办

1. 确认登录的是这家公司后台  
2. 运营工作台刷新后再看  
3. 身份不对时到小程序「我的」切换  
4. 仍不行：按《所有人先看》里的格式发群 + 整屏截图
