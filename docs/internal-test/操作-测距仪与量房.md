# 操作手册 · 测距仪与量房

给测量员（阿强）和组织者串场用。先读完《所有人先看》和《角色-测量员》，再按这一份操作。

主要用：**手机小程序**。电脑网页不能量房。

Word：`装修服务内测-操作-测距仪与量房.docx`

---

## 1. 先看这两条

1. **正式量房只能从已指派任务进**
   工作台任务卡上的「立即量房 / 继续量房 / 新增量房」，或预约详情里的「开始量房 / 继续量房」。
   「链接测距仪」只负责连设备，**不会**直接打开量房编辑器。
2. **电脑网页不能量房**
   只能在测量员手机小程序里量。

打勾：

- [ ] 明白：连仪 ≠ 进编辑器；进编辑器必须带着任务

---

## 2. 测距仪准备

### 设备要先归本公司

测距仪须已由平台分配到你们公司。未分配、或分到别的公司时，手机能搜到仪，但连接时会校验失败（常见提示：未指派企业 / 无权使用该公司设备）。

### 手机权限

打开手机蓝牙；按系统提示允许定位等相关权限（搜蓝牙设备时会用到）。

### 怎么连

1. 用测量员身份打开 **工作台**
2. Hero 按钮：**链接测距仪 · 已连接 / 未连接**
3. 弹出选设备 → 选本公司仪 → 连上后按钮应变为「已连接」

量房编辑器底部也有「测距」入口：未连接时会问你要不要去连；已连接则可直接读数。

### 常见失败

| 现象 | 先查什么 |
| --- | --- |
| 搜不到 / 连不上 | 蓝牙是否开、权限是否给、仪是否开机 |
| 能搜到但校验失败 | 仪是否已分配给本公司；是不是别人公司的仪 |
| 显示已连接但读不出数 | 退出重连一次；仍不行截整屏发群 |

打勾：

- [ ] 工作台能看到「链接测距仪」状态
- [ ] 本公司仪能连上，变成「已连接」
- [ ] （可选）故意拿未分配 / 别家仪试一次 → 应连不上或提示无权

## 3. 进入量房

前提：系统已把这单派给你（或你出示活动码后本人负责量房）。

可选入口（都算「从任务进」）：

1. 工作台「今日待上门任务」→ **立即量房 / 继续量房 / 新增量房**
2. 工作台进「量房路线 / 日程」→ 打开预约 → **开始量房 / 继续量房**
3. 预约详情同一按钮

说明：

- 还没有合格正式户型时，预约详情里 **不应** 出现可点的「确认完成量房」（或点了服务端会拒绝）
- 客户服务页只会看到量房摘要 / 预览，**不能**进编辑器改图

打勾：

- [ ] 能从任务卡或预约详情进编辑器
- [ ] 没画完合格户型时，完不成预约

---

## 4. 编辑器怎么量（逐步）

唯一正式量房页：量房编辑器（全屏画布）。顶部有 **引导**，可随时打开跟着提示做。

### 4.1 画第一面墙

1. 底部点 **重置光标**（需要时），或把橙色光标拖到墙边 / 空白处放下
2. **从光标沿墙体方向拖出**一条预览线，松手确认方向
3. 录入长度（二选一即可）：
   - 已连测距仪：点底部 **测距**，确认读数落图。还没拉出墙就点测距，会提示「请先拉出一条墙」，不会提示打开数字修改
   - 未连接也可：右侧工具栏点 **输入**，用弹出的数字键盘手输毫米数再确认
4. 继续拖下一面墙 → 再测 / 再输长度 → 围一圈

### 4.2 闭合房间

端点快回到起点、或出现可闭合提示时，画布上会出现 **「合」**：点一下，闭合当前空间。

至少要有 **一个已闭合空间**，才能点顶部 **完成** 提交正式量房。只保存草稿不算提交；编辑器「完成」也还不算线索「量房完成」，须再到预约详情点「确认完成量房」。

### 4.3 靠哪一侧墙起步

起步时若提示确认测量位置：红线要和你贴墙测量的那一侧一致，按界面箭头切换即可。
（光标贴到已有墙时，也可能显示贴「内边」或「外边」——跟着现场靠墙位置选，不用记术语。）

### 4.4 保存与完成

| 按钮 | 作用 |
| --- | --- |
| 顶部 **保存** | 保存草稿，可稍后继续 |
| 顶部 **完成** | 提交正式户型；须至少一个闭合空间，否则会提示失败。量房完成仍要在预约详情确认 |

### 4.5 门窗、撤销、清空

- 点选已有墙 → 浮动工具：**添门 / 添窗 / 复尺 / 删除**
- 底部：**撤销 / 重做**
- 左侧栏 **清空**：整幅重画（会二次确认，不可撤销）

打勾：

- [ ] 能拖方向 + 测距或手输长度画出墙
- [ ] 能点「合」闭合至少一个空间
- [ ] 顶部「完成」成功；未闭合时点「完成」会提示失败

---

## 5. 量完之后

1. 回到该单的 **预约详情**
2. 点 **确认完成量房**（须已提交带闭合空间的正式量房）
3. 预约结束后，设计师才能按进度出图；客户在服务页只能看摘要 / 预览，不能改图

打勾：

- [ ] 「确认完成量房」成功，预约变为已完成
- [ ] 客户侧能看到量房结果摘要，不能进编辑器

---

## 6. 故意试一下（应失败或应允许）

- [ ] **未连接测距仪**：仍可用右侧「输入」手动量墙（当前产品允许）；点「测距」会提示去连接
- [ ] **已连接但还没拉出墙**：点底部「测距」提示「请先拉出一条墙」，不出现「请先打开数字修改」
- [ ] **客户 / 推广人**身份打开量房编辑器 → 应被拒绝（提示当前身份不能进入）
- [ ] **未闭合就想完成预约** → 「确认完成量房」不可用，或服务端提示须先完成正式量房
- [ ] 从「链接测距仪」连上后，页面仍停在工作台，**没有**自动跳进编辑器

说明：设计师默认做方案，不走测量员日常任务卡；若本人出示活动码兼任测量，则从**自己的任务**进编辑器量房——这是正常路径，不是漏洞。

---

## 7. 极简流程（对照用）

```text
链接测距仪（可选，可后连）
        ↓
从已指派任务进入量房编辑器
        ↓
拖方向 → 测距或手输 → 连续墙 →「合」闭合
        ↓
顶部「完成」提交正式量房
        ↓
预约详情「确认完成量房」
```

---

## 卡住了怎么办

1. 确认「我的」身份是测量员（或活动码兼任测量）
2. 没有任务：先确认是否已派给你、预约是否过期
3. 连不上仪：看第 2 节表格
4. 按《所有人先看》格式发群 + **整屏截图**
