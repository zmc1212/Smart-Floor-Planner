## 怎么发

1. **先发全员**：`装修服务内测-所有人先看.docx`（必读，含流程图）
2. **领角色后再发对应一份**：
   - `装修服务内测-角色-老板.docx`
   - `装修服务内测-角色-设计师.docx`
   - `装修服务内测-角色-测量员.docx`
   - `装修服务内测-角色-介绍人.docx`
   - `装修服务内测-角色-客户.docx`
3. 账号 / 后台网址私发；不要发开发计划长文
4. 组织者自己留：`装修服务内测-角色-组织者.docx`
