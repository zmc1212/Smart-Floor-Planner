# 内测材料目录（发给同事用这里）

## 怎么发

1. **时间紧、先让所有人理解系统**：`装修服务内测-快速版.docx`（10 分钟理解、30 分钟核心链路）
2. **讲解新工作流**：`新工作流产品讲解.pptx`（从获客、服务协作、AI 方案到签单提成）
3. **完整内测**：先发 `装修服务内测-所有人先看.docx`（必读，含流程图）
4. **完整内测领角色后再发对应一份**：
   - `装修服务内测-角色-老板.docx`
   - `装修服务内测-角色-设计师.docx`
   - `装修服务内测-角色-测量员.docx`
   - `装修服务内测-角色-推广人.docx`
   - `装修服务内测-角色-客户.docx`
5. **测量员量房当天另发（或与测量员说明书同发）**：`装修服务内测-操作-测距仪与量房.docx`（连仪 + 编辑器逐步操作；可单独发放）
6. 账号 / 后台网址私发；不要发开发计划长文
7. 组织者自己留：`装修服务内测-角色-组织者.docx`
