# 角色说明书 · 客户（李女士 / 王先生）

先读完《所有人先看》，再读这一份。主要用：**手机微信**。

组织者会告诉你：你是 **李女士**（扫介绍人码）还是 **王先生**（扫员工活动码）。两人必须用 **两个微信**。

---

## 你负责什么

- 扫码领取免费上门量房和设计
- 预约上门、在允许时间内改期
- 看户型摘要和已发布的效果图  
- **不能** 自己取消预约、不能量房、不能进员工工具

---

## 你在流程图里的位置

### 李女士（朋友介绍）

```text
扫老周推广码 → 授权手机号
    ↓
看到设计师微信资料（无公司名）
    ↓
预约上门 →（可改期）→ 等量房
    ↓
看方案 → 等公司签单
```

### 王先生（员工活动码）

```text
扫小美或阿强活动码 → 授权手机号
    ↓
领取页仍然没有装修公司名；成功页是设计师个人微信
    ↓
可预约上门（立刻量房是员工做的，客户进不去量房编辑器）
    ↓
看方案
```

---

## 李女士怎么测

1. 扫描老周打开的 **推广服务码**  
2. 先看免费服务说明，再点允许手机号  
3. 成功后应看到设计师姓名、微信号、个人二维码  

打勾：

- [ ] 授权前公司后台还没有你的单；授权后才有  
- [ ] 领取页 **没有公司名**  
- [ ] 底部只有：服务、我的  
- [ ] 「服务」有当前进度和 **一个** 下一步按钮  
- [ ] 能预约上门；只能选系统给出的时间  
- [ ] 提前足够时可改期；太近了改不了，界面也不假装能改  
- [ ] **没有** 取消预约按钮  
- [ ] 量房后能看户型摘要，不能自己画图  
- [ ] 设计师发布后能看到方案；撤回后看不到  
- [ ] 把预约页转给别人 → 对方看不了详情  

### 过期时

- [ ] 显示「预约已过期」  
- [ ] 能 **重新预约**（约新的一趟）  
- [ ] 不要还去点「改期」旧时间  

---

## 王先生怎么测

- [ ] 扫的是员工 **活动码**，不是老周推广码  
- [ ] 领取/授权页 **没有** 装修公司名（和李女士一样）  
- [ ] 成功页仍是设计师个人微信  
- [ ] 能预约上门；**不能**自己打开量房编辑器  
- [ ] 后续看方案与李女士类似  
- [ ] 老周进度里不应出现你  

---

## 卡住了怎么办

1. 「我的」确认是客户身份  
2. 扫不了：确认码的种类（推广码 / 活动码）  
3. 约不了：是否上班时间、是否已有预约、是否该点「重新预约」  
4. 按《所有人先看》格式发群 + 整屏截图（含顶部微信按钮那一块）
