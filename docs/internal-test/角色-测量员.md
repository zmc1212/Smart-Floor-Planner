# 角色说明书 · 测量员（阿强）

先读完《所有人先看》，再读这一份。主要用：**手机**。

---

## 你负责什么

- 看今天要去哪一户、维护自己不能上门的时间
- 从 **已指派任务** 进入正式量房，画完并提交
- 预约详情里可补地址、导航；量完后才能「确认完成量房」
- 在「收益」看自己的提成  
- **没有**「设计」发布入口；不能看介绍人收益规则配置

---

## 你在流程图里的位置

```text
系统预分配你为测量员
        ↓
按预约上门（或员工活动码当场量房）
        ↓
正式量房编辑器 → 提交
        ↓
确认完成量房 → 后面交给设计师出图
```

员工活动码：如果你是出示人，你负责量房，系统另派设计师；冲突时 **不会** 自动换人。

---

## 入职

1. 扫 **员工入驻码** → 允许手机号 → 选 **测量员**  
2. 可不传个人二维码  

打勾：

- [ ] 已是测量员，马上能用  
- [ ] 底部有：工作台、客户、收益、我的（没有「设计」）  

---

## 日常量房（李女士这一单）

- [ ] 工作台能看到已安排给你的任务  
- [ ] 从工作台进「日程」，已确认预约在列表里  
- [ ] **只能从任务进入量房**，不要在别的菜单找  
- [ ] 没提交合格户型时，点「确认完成量房」应失败  
- [ ] 提交后进度「量房完成」；客户只能看摘要，不能自己改图  
- [ ] 电脑网页不能量房（这是规定）  

有地图坐标时，「导航」应能打开微信地图。

---

## 员工活动码

- [ ] 能出示个人活动码；**出示页**可以有公司名  
- [ ] 你出示则你负责量房，系统另派设计师  
- [ ] 你可以先预约或立刻量房；客户不能进量房编辑器  
- [ ] 时间冲突不会偷偷换测量员，应换时段  
- [ ] 「收益」有自己的提成；老周看不到这一单  

---

## 过期之后

- [ ] 过期预约 **不在**「已确认」里占位子  
- [ ] 在待处理或历史里还能找到  
- [ ] 客户重新约成功后，新预约替换旧的待办，不要重复两条  

---

## 故意试一下（应失败）

- [ ] 阿强身份去找「设计」发布 → 不应有入口 / 硬进被拒  
- [ ] 客户或介绍人身份不能打开你的量房编辑器  

---

## 卡住了怎么办

1. 确认「我的」里是测量员  
2. 没有任务时先确认是否已派给你、预约是否过期  
3. 按《所有人先看》格式发群 + 整屏截图
