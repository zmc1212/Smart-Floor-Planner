# 角色说明书 · 设计师（小美）

先读完《所有人先看》，再读这一份。主要用：**手机**（偶尔电脑）。

---

## 你负责什么

- 入职后补全微信号和个人微信二维码（客户加你用）
- 帮客户预约 / 改期，必要时取消（填原因）
- 量房完成后出效果图，并 **主动发布** 给客户看
- 可协助签单；在「收益」看自己的提成  
- **不能**维护测量员请假；不要从无关入口乱进量房

---

## 你在流程图里的位置

```text
客户领完服务 → 你被自动安排为设计师
        ↓
帮约上门（或客户自己约）
        ↓
阿强量完房 → 你出图并发布
        ↓
签单 → 你的「收益」出现一笔
```

员工活动码：如果你是出示人，你可能 **兼任设计师 + 测量员**。

---

## 入职

1. 扫张总发的 **员工入驻码**（不是推广人码）  
2. 允许手机号 → 选择 **设计师**  
3. 打开「我的」→ 填微信号 → 上传个人微信二维码  

打勾：

- [ ] 已是设计师，马上能用，不用审核  
- [ ] 微信号和二维码已齐全  
- [ ] 底部有：工作台、客户、设计、收益、我的  

---

## 朋友介绍这一单（跟李女士）

- [ ] 李女士领取成功后，工作台能看到她  
- [ ] 打开该客户线索详情，可看到「开始量房」或「继续量房」；已有户型时还有「新增量房」
- [ ] 可代约上门；若客户已约，再约应提示已有预约  
- [ ] 客户改期后，你看到的时间同步变化  
- [ ] 上门前很近时，客户改不了，你或老板可填原因改期  
- [ ] 客户没有「取消」按钮；取消只能你或老板做  

### 出图与发布

- [ ] 底部「设计」能为这一单出图  
- [ ] **不发布**时，李女士看不到图  
- [ ] **发布**后，李女士服务档案出现方案；进度「方案已发布」  
- [ ] 撤回后，李女士马上看不到  

### 签单与收益

- [ ] 签单后「收益」能看到自己这一笔  
- [ ] 朋友介绍：台账共 3 笔；活动码：共 2 笔  

---

## 员工活动码这一单（跟王先生）

- [ ] 能出示 **个人活动码**（不是老周那种推广码）  
- [ ] **你出示码的页面**可以有公司名；客户扫进来的领取页没有公司名  
- [ ] 客户授权后，你兼任设计+量房（若是你出示）  
- [ ] 你可以先预约，也可以立刻进量房；王先生不能替你量房  
- [ ] 预约冲突时 **不会** 自动换成别人，应换时间  
- [ ] 老周进度/收益里看不到王先生  

---

## 过期重约

- [ ] 过期后工作台有待处理，能帮约 **新的一趟**（不是改旧单）  
- [ ] 不要把过期单还当成「正在进行」  

---

## 故意试一下（应失败）

- [ ] 用设计师身份，不要期望有测量员专属「随便量房」入口  
- [ ] 转发别人的预约链接给无关微信 → 对方应看不了  

---

## 卡住了怎么办

1. 「我的」确认当前是设计师身份  
2. 资料不全时新客户可能排不到你  
3. 按《所有人先看》格式发群 + 整屏截图
