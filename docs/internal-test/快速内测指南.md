# 家客来装修服务 · 快速内测指南

给第一次参加内测的同事使用。目标不是一次测完所有功能，而是在 **10 分钟理解系统、30 分钟跑通一条核心服务链路**。

Word 发放版：`装修服务内测-快速版.docx`。

## 系统是做什么的

家客来把装修公司的获客、服务协作和方案交付串在一起：

```text
推广/员工发码或老板建客 → 客户预约 → 测量员量房 → 设计师出方案并发布 → 客户查看 → 老板签单、记提成
```

客户只能看到自己的服务；员工只处理分给自己的客户；老板查看全店并处理派单和提成。

## 30 分钟怎么跑

组织者应提前准备好：同一企业下的老板、设计师、测量员、推广人和客户账号；可用的推广服务码；已可派单的设计师和测量员；一条指定的测试线索。若要测试签单，必须明确指定这条线索可用于测试签单。

1. **0–5 分钟：老板准备** — 确认员工可派单、推广码能打开、预约规则和提成规则已启用。
2. **5–10 分钟：推广人和客户** — 推广人出示服务码；客户扫码授权并预约。老板确认线索已出现且已派设计师、测量员。
3. **10–20 分钟：测量员和设计师** — 测量员从任务进入量房并提交一个已闭合空间；设计师查看线索、补现场图（先选房间标签），进入 AI 设计并发布一套方案。
4. **20–25 分钟：客户验收** — 客户看到预约/服务进度、量房摘要和已发布方案；未发布的方案不应可见。
5. **25–30 分钟：老板收尾** — 仅对指定测试线索执行签单，确认朋友介绍生成推广人、设计师、测量员三笔提成。

没有真机测距仪或 AI 服务暂不可用时，记录为“设备/供应商环境”，先继续验证手工量房或既有方案的发布、客户可见性。

## 每个人只看自己的三件事

| 角色 | 三件事 |
| --- | --- |
| 老板 | 员工可派单；客户已分给对的人；签单后提成正确。 |
| 推广人 | 能出示推广码；能看到脱敏进度；看不到客户电话、地址、户型和方案文件。 |
| 客户 | 能领取和预约；只能看自己的服务；发布后才能看到方案。 |
| 测量员 | 从已派任务进入量房；至少闭合一个空间再完成；确认完成量房后任务交给设计师。 |
| 设计师 | 能查看已分客户；现场图先选房间标签；方案发布后客户可见、撤回后不可见。 |

## 这几种现象是正常规则

1. 客户扫码授权页不显示装修公司名；员工自己出示活动码的页面可以显示。
2. 客户不能取消预约、不能进入量房编辑器，也不能看到别人的服务。
3. 电脑后台不能量房；正式量房只能由已派任务的员工在手机小程序进入。
4. 没有主动发布的方案，客户看不见。
5. 朋友介绍签单为三笔提成；员工活动码或老板手工建客为设计师、测量员两笔提成。

## 一眼判断要不要报问题

- **立即报：** 领不了服务、派错人/派不到人、预约或量房数据丢失、客户看到别人信息、发布后客户仍看不到、签单提成不对。
- **记录后报：** 文案、布局、提示不清楚，或微信通知没有收到但页面状态正确。
