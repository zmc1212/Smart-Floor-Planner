This is not production rollback or pre-login connectivity acceptance.

1. Verify the remote engine with `docker info`, then maintain compose from
   `D:/Smart-Floor-Planner-Dev/` over SSH. Do not run the full-stack compose with
   local `G:` bind paths.
2. For rollback, remove `SFP-Remote-Dev-Tunnel.lnk` from the current-user Startup
   folder. Verify command lines, then stop the dedicated PowerShell supervisor running
   `admin/scripts/remote-dev/tunnel.ps1` before its SSH child; killing only SSH triggers
   automatic reconnection. Confirm local ports5432/55432 are free. Do not touch the Embedding tunnel.
3. Start local Docker Desktop, run `docker context use desktop-linux`, and start
   the original containers against their preserved volumes. Do not delete remote
   volumes.
4. If the remote environment has received writes, take a backup and migrate
   those writes back before switching. The old local source is a cutover snapshot,
   not a lossless direct rollback target.

Before stopping or restarting any process, inspect its PID, executable path,
command line, owner, and task/container identity. Operate only a process whose
dedicated ownership is verified; never use a generic process-name match for
Python, SSH, Docker, or ComfyUI.
